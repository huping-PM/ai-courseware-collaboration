# 课件文案与口播编排

## 输入与输出

- 输入：来源文本、受众/目标和已确认业务口径；没有明确口径时标待确认。
- 输出：project.json、来源对应及文案审核事项。
- 适用范围：PPT知识讲解视频基础路线。文案由宿主文本模型编排；脚本只检查数据结构，不自动写作或事实核验。

## 执行

1. 读取[数据契约](../video-workflow/references/data-contract.md)，按[示例结构](../video-workflow/references/project-example.json)建立任务自己的project.json。
2. 一页表达一个核心观点，屏幕文字与完整口播分开。保持政策/专业术语、数字与限定条件，不为降低文字相似度改错事实。
3. 为页、要点、口播语句赋稳定ID，显式写bullet.segment_id；不要凭模糊文本相似度猜音画对应。source_refs定位来源，不能用来源文件名代替内容证据。
4. 基础版最多5个要点；以渲染器容量检查为准，长内容拆页，不压小字号硬塞。配色、页数、语速和字幕要求按用户任务，不沿用25页案例。
5. 运行[数据校验](scripts/validate_project.py)。交付文案和未决项供确认；通过结构校验不代表知识内容正确。

## 工具入口

在命令中将`<本技能>`替换为本SKILL.md所在目录，`<任务>`替换为用户指定输出目录；Python/Node使用当前环境实际可执行路径。路径含空格时保留引号。

```text
python "<本技能>/scripts/validate_project.py" --project "<任务>/project.json"
```

## 依赖与交接

本技能属于视频创作技能套件，须保留兄弟目录`video-workflow`，共用[数据契约](../video-workflow/references/data-contract.md)和[依赖说明](../video-workflow/references/dependencies.md)。复制单个节点时应同时带上该公共依赖，或由目标平台注册对应工具；不要只导入SKILL.md就声称脚本可执行。

## 失败与完成标准

- 缺输入、工具、账号权限或资源时，准确指出阻碍及可继续的工作，不伪造产物或检查结果。
- 工具报错先读原因，不循环盲重试；输出覆盖默认拒绝，保留已有人工成果。
- 完成时给出真实文件路径、执行过的检查、未检查项和下一节点。结构有效、文件生成、视觉通过、业务确认分别记录。
- 在用户授权范围内推进；本技能不自带外部发布、全局安装或后台监控授权。
