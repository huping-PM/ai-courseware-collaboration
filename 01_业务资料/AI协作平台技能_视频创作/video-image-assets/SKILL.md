# 课件配图与素材处理

## 输入与输出

- 输入：页面语义与视觉要求，或已获授权的本地图片。
- 输出：页面配图、素材对应清单、处理后图片和视觉检查记录。
- 适用范围：PPT知识讲解视频基础路线。内置的是图片预处理，不内置生图账号/模型，不承诺去除水印或重建未知版权素材。

## 执行

1. 读取[数据契约](../video-workflow/references/data-contract.md)，逐页确定图片表达的主体、动作与关系；无需配图的页不强行生成。
2. 已有图片优先复用；要求生图时调用当前实际可用的宿主生图工具或用户授权API。不把技能名称当作模型权限，不擅自使用未确认的服务或账号。
3. 生成/处理后查看图片，检查语义、伪文字、比例和系列风格；不能仅凭文件存在判断质量。固定绿色/3D风格只是原案例，非本技能强制条件。
4. 在project中填本地image路径，运行[素材预处理](scripts/prepare_images.py)。PNG透明信息保留，照片转JPEG，等比例缩放。
5. 检查assets-manifest后显式更新project.image到正确相对路径；脚本不偷偷改原稿。保存素材授权说明，重新校验project并按总流程更新受影响成果。

## 工具入口

在命令中将`<本技能>`替换为本SKILL.md所在目录，`<任务>`替换为用户指定输出目录；Python/Node使用当前环境实际可执行路径。路径含空格时保留引号。

```text
python "<本技能>/scripts/prepare_images.py" --project "<任务>/project.json" --output "<任务>/assets-prepared"
```

## 依赖与交接

本技能属于视频创作技能套件，须保留兄弟目录`video-workflow`，共用[数据契约](../video-workflow/references/data-contract.md)和[依赖说明](../video-workflow/references/dependencies.md)。复制单个节点时应同时带上该公共依赖，或由目标平台注册对应工具；不要只导入SKILL.md就声称脚本可执行。

## 失败与完成标准

- 缺输入、工具、账号权限或资源时，准确指出阻碍及可继续的工作，不伪造产物或检查结果。
- 工具报错先读原因，不循环盲重试；输出覆盖默认拒绝，保留已有人工成果。
- 完成时给出真实文件路径、执行过的检查、未检查项和下一节点。结构有效、文件生成、视觉通过、业务确认分别记录。
- 在用户授权范围内推进；本技能不自带外部发布、全局安装或后台监控授权。
