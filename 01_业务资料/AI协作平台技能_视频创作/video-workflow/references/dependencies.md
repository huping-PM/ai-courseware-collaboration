# 执行依赖与能力边界

本套件是文件式技能库，不是桌面插件或已部署的Web服务。按完整目录搬运，子技能通过相对路径共享video-workflow/scripts/common.py。目标智能体必须能读取文件、运行受控命令、保存成果；只有文本聊天能力时只能形成内容与执行方案。

## 按节点安装，而非全部必装

| 节点 | 依赖 | 可替代性 |
|---|---|---|
| 数据检查/环境预检 | Python 3.10或以上；仅标准库 | 不需账号 |
| TXT/MD提取 | Python标准库 | 宿主文件读取也可 |
| DOCX/PDF提取 | python-docx / pdfplumber，按格式选装 | 扫描件另用OCR；未提供OCR引擎 |
| 图片预处理 | Pillow | 图片生成由宿主图像工具或用户授权服务完成；本包不内置生图模型 |
| 可编辑PPT | python-pptx、Pillow及其依赖、目标字体 | 不需要腾讯PPT插件或原模板；真正的PPT预览器另接 |
| 配音桥接 | 仅选择edge-tts桥接时需要edge-tts与联网 | 可由其他TTS先产单句音频；Intel AIPC/克隆声音不是公共依赖 |
| 音频归一化 | 相同采样率单声道PCM16 WAV可直接处理；其他输入需FFmpeg | 单句实际时长以样本计，不按字数猜 |
| HTML生成 | Python标准库、真实时间轴/音频；图片路径需有效 | 样式/动画内嵌，不依赖旧anim.js |
| 帧渲染 | Node.js、puppeteer-core或playwright之一、Edge/Chrome可执行文件 | 浏览器阅读插件不能替代此本地执行器 |
| 合成 | FFmpeg，Python，Pillow用于图片尺寸检查 | FFmpeg可独立提供或由imageio-ffmpeg取得；不包含FFprobe保证 |
| 成片属性检查 | FFprobe、Python | 只安装FFmpeg未必具备FFprobe；缺探测工具必须标记未检查 |

版本以目标机器实际测试为准。环境预检只报告发现状态，既不联网探测账号，也不证明所有版本兼容。默认路径全部由调用者提供，不带原作者用户名。安装应使用该任务的隔离环境，勿覆盖其他项目依赖。

## 基础部署命令示意

在获准部署的执行环境中创建venv后，可选择安装：

```text
python -m pip install python-pptx Pillow
python -m pip install python-docx pdfplumber
python -m pip install edge-tts
```

后三个命令组均按节点需要选择，不代表首次使用全部安装。Node渲染可在video-frame-render/scripts中安装package.json声明的puppeteer-core；已有playwright可直接用`--engine playwright`，不重复下载浏览器。实际浏览器路径通过`--browser`传入。记录安装成功的确切版本用于生产复现，不把参考版本当兼容认证。

## 真实能力与未实现范围

- 基础讲解页面：标题、1—5要点、可选单图、逐句口播；PPT内容同源，视觉不是逐像素复刻。
- 生图：技能给执行流程和素材处理，实际出图由目标宿主能力决定。包内不保存API密钥。
- TTS：edge脚本会真实联网；创建技能或跑离线测试不自动调用。未执行服务测试不能声明语音服务已接通。
- 质量：包含结构/资源/媒体属性检查及人工清单，不具备原清单全部像素审计、发音检测和业务语义验收。
- 不包括：任意PPT动画解析、复杂角色动画、剪辑器、字幕/BGM、平台权限/审批接口、后台任务队列及付费模型订阅。
- 样例和测试音用于验证工程行为，不能作为业务样片或真实配音交付。

## 来源与适配取舍

方法来源于用户提供的《PPT视频量产流程清单》与原16技能目录；本套件重新实现基本节点，不复制不完整的旧脚本，不要求旧25页PPT。

保留同源内容、真实音频时间轴、确定性渲染、显式限帧、人工确认；修正旧案例固定13页、TAIL不一致、旧片段静默复用、缺帧跳过、无字幕请求仍产两版等问题。文字容量、主题与页数不沿用原案例硬编码。当前模板能力和验证范围以本包验证记录为准。
