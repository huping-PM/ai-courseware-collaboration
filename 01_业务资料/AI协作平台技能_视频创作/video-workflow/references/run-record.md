# 任务运行记录模板

在用户任务目录复制本结构，按实际证据填写。不要将示例值当作用户业务确认。

| 字段 | 记录内容 |
|---|---|
| 任务目标/交付版本 | 用户要求及来源 |
| 原稿与project版本 | 文件位置、project SHA256 |
| 生图/TTS来源 | 实际工具、音色、设置；不记密钥 |
| 人工确认依据 | 确认内容、版本、消息或文件来源；未确认写未确认 |
| 节点状态 | 未开始/执行中/失败/已生成/已检查，分别列出 |
| 节点成果 | source/project/ppt/voice/animation/frames/video/quality实际路径 |
| 修改与失效范围 | 哪些输入变了、哪些成果需重建 |
| 自动检查 | 实际命令、结果、报告路径 |
| 人工复核与业务审核 | 已核对内容、未核对内容、批准依据 |
| 失败接续 | 错误原因、保留结果、新运行目录、下一步 |

仅文件生成或自动项通过时，不填写“主管已审核”或“业务验收通过”。
