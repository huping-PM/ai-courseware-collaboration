# 视频创作总流程

## 输入与输出

- 输入：原稿或已有节点产物、期望交付物、用户已确认的内容与效果。
- 输出：任务状态记录、各节点成果链接、实际验证结果和未决事项。
- 适用范围：PPT知识讲解视频基础路线。本入口是智能体执行方法，不是常驻调度服务；自动后台队列、账号管理、平台上传和主管审批接口未实现。

## 执行

1. 读取[数据契约](references/data-contract.md)与[依赖和验证边界](references/dependencies.md)。根据已有成果定位起点，不要求用户重复提交已确认资料。
2. 用[环境预检](scripts/check_environment.py)只读检查；工具缺失才处理对应依赖。优先使用已有宿主能力，不强制安装所有候选服务。
3. 按任务需要调用兄弟技能：资料读取→文案与口播→配图→PPT→配音时间轴→动画→逐帧→合成→检查。每个技能的入口在本目录上一级；使用[节点索引](references/nodes.md)定位。已有有效成果可以跳过上游。
4. 用户确认要求有记录才视为确认；未指定时建议文案/画面/试听三个检查点，可合并审阅。已有明确授权不反复询问。缺账号不自动等于无TTS能力，先查已授权的宿主/本地/edge-tts路径。
5. 用[任务记录模板](references/run-record.md)在任务目录保存输入版本、已生成/已检查/已确认状态和节点路径。引用[基础示例](references/project-example.json)了解格式；示例内容不得混入用户课件。
6. 变更文案/音色：重新配音、时间轴及全部视频下游；变更版式/配图：重新PPT、动画、渲染、合成与检查。输入JSON摘要改变时不手改timeline摘要绕过校验，重新从已有有效单句音频构建时间轴；先确认语句文字没变。
7. 渲染/合成使用新运行目录，缺页缺帧明确失败。只交付用户要求的版本；基础工具产无字幕视频，需要字幕、人物或复杂场景时另行设计扩展。
8. 报告生成、自动检查、人工复核和业务审核各自结果；不得将技能导入成功等同于视频能力已接入平台。

## 工具入口

在命令中将`<本技能>`替换为本SKILL.md所在目录，`<任务>`替换为用户指定输出目录；Python/Node使用当前环境实际可执行路径。路径含空格时保留引号。

```text
python "<本技能>/scripts/check_environment.py" --output "<任务>/environment.json"
```

## 依赖与交接

本技能属于视频创作技能套件，须保留兄弟目录`video-workflow`，共用[数据契约](references/data-contract.md)和[依赖说明](references/dependencies.md)。复制单个节点时应同时带上该公共依赖，或由目标平台注册对应工具；不要只导入SKILL.md就声称脚本可执行。

## 失败与完成标准

- 缺输入、工具、账号权限或资源时，准确指出阻碍及可继续的工作，不伪造产物或检查结果。
- 工具报错先读原因，不循环盲重试；输出覆盖默认拒绝，保留已有人工成果。
- 完成时给出真实文件路径、执行过的检查、未检查项和下一节点。结构有效、文件生成、视觉通过、业务确认分别记录。
- 在用户授权范围内推进；本技能不自带外部发布、全局安装或后台监控授权。
