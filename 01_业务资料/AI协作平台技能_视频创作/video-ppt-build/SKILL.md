# 课件PPT制作

## 输入与输出

- 输入：符合契约的project.json及所引用图片。
- 输出：可编辑PPTX，逐页口播备注；另记录结构与视觉复核结果。
- 适用范围：PPT知识讲解视频基础路线。基础模板不还原任意上传PPT，不实现复杂图表或PowerPoint原生动画；品牌模板和复杂布局可另定制。

## 执行

1. 读取[数据契约](../video-workflow/references/data-contract.md)，核对文案确认依据与资源路径。
2. 运行[基础PPT生成器](scripts/build_ppt.py)。生成16:9标题/要点/可选图布局及演讲者备注，不依赖原案例PPT或腾讯插件。
3. 容量不足时返回文案节点拆页或在用户认可后设计新模板；不要缩字号绕过限制。
4. 检查页数、逐页标题、图片比例和备注完整性；使用可用的PPT预览/导出工具目视检查。未有实际PPT渲染器时标视觉待复核，HTML预览不能冒充PPT渲染。
5. 使用新文件名输出，交付PPT和验证记录。

## 工具入口

在命令中将`<本技能>`替换为本SKILL.md所在目录，`<任务>`替换为用户指定输出目录；Python/Node使用当前环境实际可执行路径。路径含空格时保留引号。

```text
python "<本技能>/scripts/build_ppt.py" --project "<任务>/project.json" --output "<任务>/course.pptx"
```

## 依赖与交接

本技能属于视频创作技能套件，须保留兄弟目录`video-workflow`，共用[数据契约](../video-workflow/references/data-contract.md)和[依赖说明](../video-workflow/references/dependencies.md)。复制单个节点时应同时带上该公共依赖，或由目标平台注册对应工具；不要只导入SKILL.md就声称脚本可执行。

## 失败与完成标准

- 缺输入、工具、账号权限或资源时，准确指出阻碍及可继续的工作，不伪造产物或检查结果。
- 工具报错先读原因，不循环盲重试；输出覆盖默认拒绝，保留已有人工成果。
- 完成时给出真实文件路径、执行过的检查、未检查项和下一节点。结构有效、文件生成、视觉通过、业务确认分别记录。
- 在用户授权范围内推进；本技能不自带外部发布、全局安装或后台监控授权。
