# 讲解视频质量检查

## 输入与输出

- 输入：成片、composition.json、原稿及PPT/动画/音频等对应版本；FFprobe用于媒体检查。
- 输出：自动检查报告、人工复核清单、返工节点和未检查项。
- 适用范围：PPT知识讲解视频基础路线。脚本是媒体属性检查器；不含OCR语义判断、自动发音评分或与PPT的逐像素一致性检查。

## 执行

1. 运行[成片探测工具](scripts/check_video.py)，实际检查帧数、分辨率、帧率、编码和音频/字幕流，不用预期参数伪造探测结果。
2. 对照项目页数与composition检查完整性。人工查看代表页、每个拼接边界，试听术语及断句，核对内容和原稿。
3. 标记自动项通过/失败与人工review_required。没有执行像素保真、逐句听辨或业务审核就不能报告“三套审计全PASS”。
4. 原清单的挤堆阈值和末帧墨量阈值不直接适用于本版；本版有明确映射且末采样帧早于duration，应按契约验证，不能制造假失败。
5. 将问题定位到文案、素材、PPT、配音、动画、渲染或合成节点；修改后重跑受影响检查。任务完成与主管业务审核按所在项目规则区分。

## 工具入口

在命令中将`<本技能>`替换为本SKILL.md所在目录，`<任务>`替换为用户指定输出目录；Python/Node使用当前环境实际可执行路径。路径含空格时保留引号。

```text
python "<本技能>/scripts/check_video.py" --video "<任务>/video-run-001/final.mp4" --composition "<任务>/video-run-001/composition.json" --ffprobe "<FFprobe路径>" --output "<任务>/quality.json"
```

## 依赖与交接

本技能属于视频创作技能套件，须保留兄弟目录`video-workflow`，共用[数据契约](../video-workflow/references/data-contract.md)和[依赖说明](../video-workflow/references/dependencies.md)。复制单个节点时应同时带上该公共依赖，或由目标平台注册对应工具；不要只导入SKILL.md就声称脚本可执行。

## 失败与完成标准

- 缺输入、工具、账号权限或资源时，准确指出阻碍及可继续的工作，不伪造产物或检查结果。
- 工具报错先读原因，不循环盲重试；输出覆盖默认拒绝，保留已有人工成果。
- 完成时给出真实文件路径、执行过的检查、未检查项和下一节点。结构有效、文件生成、视觉通过、业务确认分别记录。
- 在用户授权范围内推进；本技能不自带外部发布、全局安装或后台监控授权。
