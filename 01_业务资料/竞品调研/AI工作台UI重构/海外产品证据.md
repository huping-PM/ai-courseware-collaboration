# AI 工作台 UI 重构：海外产品证据

文件角色：官方资料提炼、横向对标与设计启发。访问日期及资料截止日：**2026-09-28**。状态：研究完成，设计建议待评审。

范围：ChatGPT、Claude、Google NotebookLM、Gemini Canvas、Notion AI、Canva AI、Runway，共 7 个产品。均为交互参考对象，不据此认定为本项目直接商业竞争者。本轮通过网页工具实际读取官方正文；没有登录体验，没有逐像素截图测量。文档存在配图或动画链接，只表示可进一步验证的视觉材料，本轮不将图片替代文字算作目视观察。

## 结论与适配方向

1. **项目、会话与成果应有各自入口。** ChatGPT 的项目上下文、Claude 的独立成果入口、Runway 的会话与资产关系，可支持本项目保留项目隔离，同时使已生成课件不必依赖翻聊天记录才能找到。
2. **资料研究适合可折叠的三分区。** NotebookLM 的 Sources / Chat / Studio 是最直接的结构参照；本项目可用“依据资料—协作对话—当前成果”，资源维护仍属于资源管理模块。
3. **文本创作适合对话与编辑器并排。** Claude Artifacts、Gemini Canvas 为选中文本后局部修改提供依据；Md 编辑需要独立保存状态与编辑区域。
4. **多媒体创作需要资产及版本视角。** Runway 的生成设置、会话与资产组织值得借鉴；输入框可识别意图，但生成前应能看懂本次处理对象、输出形式和所用工具。
5. **技能沉淀应形成可审核对象。** Notion 将持续偏好放入可编辑 Instructions 页面，ChatGPT 支持将回答保存为项目来源。由此推导，本项目“沉淀技能”宜先形成名称、适用范围、触发方式、正文预览，再由人确认保存。这是本项目建议，不是上述产品均已具备相同技能流程的事实。

### E-INT01｜ChatGPT：以项目承载持续对话

**可确认事实。** Projects 汇集相关聊天、文件与项目指令；可从侧栏新建项目。项目来源可以预览、下载；回答可以保存为项目来源复用。项目指令从项目设置管理，只在该项目内适用。官方文档还区分项目专属记忆与默认记忆，所以不能把“有项目”一概等同严格数据隔离。依据：E-INT01a。

**布局与对话成果关系。** 文字及图注支持“侧栏项目入口—项目来源—项目聊天”的组织；具体宽度、色彩、当前默认空白页未经目视核验。文档列有 Canvas，但本次其独立帮助 URL 返回 404，故不补写当前 Canvas 全流程。

**迁移建议。** 工作台顶部持续显示当前项目；对话选中的资料应是可查看的上下文集合。把好回答“保存为资料”和“沉淀为技能”分成明确动作。**不照搬：** 不照搬跨项目默认记忆语义；本项目项目隔离以业务共识为准。

### E-INT02｜Claude：对话旁边形成独立可编辑成果

**可确认事实。** Projects 发布文档说明将知识与聊天归于项目并设置项目指令。当前 Artifacts 帮助说明：成果在对话旁独立窗口打开，可对话修改或直接编辑；文档／Markdown 可选中文字后发起局部修改，成果可在侧栏 Artifacts 入口重新找到。依据：E-INT02a、E-INT02b。

**布局与配置。** 并排关系有官方操作文字支持；项目知识／项目指令与成果窗口是不同职责。当前帮助说明包含新旧成果差异，不能将 2024 发布图当作 2026 当前界面。

**迁移建议。** 用“会话 + 当前成果”双工作区承接内容协作；文稿有自己的标题、保存状态和局部改写入口。**不照搬：** 不把其设计系统、互动应用与分享范围自动纳入课件首版；未核验跨项目权限体系。

### E-INT03｜NotebookLM：从依据到问答，再到可保留成果

**可确认事实。** 2024 官方说明明确 Sources 管理来源、Chat 进行带引用的讨论、Studio 生成内容；分区可调整，例如来源查看与笔记编辑并排。2026 升级说明继续保留 Studio 下载成果，支持从较模糊的问题出发收集来源，并说明用户仍控制加入的来源。依据：E-INT03a、E-INT03b。

**布局与配置。** 三分区有官方文字及动画图注证据，未实测其拖拽尺寸与折叠状态。已读来源不能证明具备本项目式技能配置库。

**迁移建议。** 研究型风格可默认呈现“资料—对话—成果”，每段核心答案保留来源定位。资源库属于项目长期资产，当前会话引用只是所选子集。**不照搬：** 不把学习指南、播客等预置输出全铺在课件首页；不能据产品导航名称推断项目隔离规则。

### E-INT04｜Gemini Canvas：在生成结果中继续局部加工

**可确认事实。** Canvas 从提示输入区启用，可生成并实时编辑文档／代码；能选中段落调整表达，导出至 Google Docs。当前产品页说明研究报告生成后，可从 Canvas 的 Create 菜单转换为网页、信息图、测验或音频概述。依据：E-INT04a、E-INT04b。

**布局与配置。** 有输入区入口、编辑区与右上 Create 动作的官方文字；没有据此认定其提供项目资源树或完整智能体配置后台。

**迁移建议。** 当前文稿页以“选中内容 → 提出修改 → 更新当前版本”为主；以成果菜单提供生图／图生视频等后续动作，保留当前素材引用。**不照搬：** 不将代码、应用制作或所有转换类型纳入本项目；不把结果转换等同已具备专用模型路由。

### E-INT05｜Notion AI：让 AI 贴近正在处理的资料

**可确认事实。** Agent 可使用当前页面、选中块、指定来源或上传文件；可切换右侧栏与浮窗聊天。Agent 能创建编辑页面与数据库，权限跟随用户。Instructions 是可编辑页面，用于持续语气、格式和规则，一次仅激活一页。依据：E-INT05a、E-INT05b。

**布局与配置。** “当前文档 + 可切换聊天面板”有官方操作文字；Instructions 管理属于配置职责。文档介绍可复用 skills，但本轮未单独读取其技能创建帮助，不推断技能包结构。

**迁移建议。** 编辑 Md 时保留旁侧 AI 辅助；智能体配置页提供可阅读、可修改的规则正文及适用范围。对话经验沉淀为技能先出草稿，不静默改变生效规则。**不照搬：** 不将 Notion 的全工作区访问逻辑直接用于本项目；不增加复杂数据库功能。

### E-INT06｜Canva AI：让对话衔接可继续编辑的设计

**可确认事实。** 官方 Canva AI 2.0 发布文章描述从目标／草图开始对话、调用设计工具、生成由可编辑对象组成的成果，并允许手动接管。文章还介绍持续记忆与品牌上下文；发布状态表述为 research preview。依据：E-INT06a。

**布局与配置。** 目前证据为官方产品主张与图注，足以支持“对话—设计编辑连续性”，不足以确认左右栏布局、当前账号可用性或实际单元素修改精度。

**迁移建议。** 多媒体成果提供“继续修改”并明确本次选择的对象；工作台入口围绕工作目标，风格统一而非堆满工具按钮。**不照搬：** 不把自动记忆视作技能自动发布，也不把自动排程、批量跨渠道生产列为本项目承诺。

### E-INT07｜Runway：多媒体会话与资产迭代

**可确认事实。** Agent 可从左侧导航或资产的 Ask Agent 进入；输入面板提供生成前确认与模型选择偏好。Sessions 归组同一创作过程中的视频变体；项目可进一步组织资产、会话与工作流；删除会话不会删除资产。依据：E-INT07a、E-INT07b。

**布局与配置。** 导航、输入面板设置及会话列表有官方操作文字；不把图注当成暗色外观的目视证据。模型偏好包含速度、成本、质量和自定义，能力适配仍影响选择；此为可观察产品规则，不是本项目的模型实现方案。

**迁移建议。** 生成图片／视频时显示输入素材、任务状态、可重试动作与成果变体；进入大预览后保留紧凑对话。资产应有稳定入口，避免会话列表承担素材库全部职责。**不照搬：** 不照搬默认自动生成或默认确认策略，本项目保留人工确认依据；不把完整时间线编辑器当成本轮 UI 必选模块。

## 三种风格的设计依据（建议，非竞品视觉复刻）

| 候选方向 | 布局重点 | 建议视觉语言 | 三模块如何承接 | 来源 |
|---|---|---|---|---|
| A 轻量对话工作台 | 窄项目导航 + 中心对话；生成后展开右侧编辑区 | 温和浅底、少边框、大留白、单一强调色 | 资源／配置独立模块，协作页按需选用；成果侧栏可收起 | E-INT01、02、04、05 |
| B 资料研究工作台 | 项目导航 + 资料、对话、成果三分区；可折叠 | 清晰纸面层级、细分隔线、紧凑资料卡、引用强调 | 资源管理保持分类与元数据；协作区展示当前引用；配置从工具入口进入 | E-INT03、05 |
| C 多媒体制作工作台 | 窄导航 + 紧凑对话 + 大预览；底部／侧边成果变体 | 深色预览舞台、浅色或分层操作面板、强缩略图 | 资源模块浏览素材；配置维护可用技能／工具；协作页识别意图并生成 | E-INT06、07 |

三方向均需保留当前项目、返回原系统、资源管理、智能体配置、内容协作智能体的稳定入口。上述色彩、宽度取舍和模块映射是针对本项目提出的设计方案，不能用来描述竞品当前实页。

## 待确认与后续验证

- 候选风格需用同一份真实课件和相同操作路径比较，避免仅比较首页观感。
- 大预览与三栏模式下，Md 编辑、长标题、素材缩略图和中文提示词的可读宽度需由原型验证。
- 智能体自动选择专用模型的真实能力、调用失败、权限隔离和保存机制由本项目需求及实现验证；竞品公开说明只能提供交互参考。
- 最终要用于精确外观参考时，应另行打开官方图片／演示或授权账号实页目视核验。本轮不声称完成该层验证。
- 读取受阻：ChatGPT Canvas 独立帮助页返回 404；Anthropic 旧 Artifacts 新闻页读取失败；已采用有效 Projects／当前 Artifacts 帮助正文补充，失败页不计有效来源。
