# AI 协作平台技能包

## 收录范围

本包仅包含可独立安装的本机技能文件夹；不含插件、连接器和运行环境工具。

## 已收录技能（12 个）

| 类别 | 技能文件夹 | 用途 |
| --- | --- | --- |
| 调研与规则 | `agent-reach` | 检索网页、平台和外部资料，沉淀有来源的调研结论。 |
| 调研与规则 | `huayu-workflows` | 调用保险、课程开发等既有业务规则。 |
| 方案审核 | `grill` | 风险审视与预演。 |
| 方案审核 | `grill-me` | 逐题澄清方案与决策分支。 |
| 方案审核 | `grill-with-docs` | 压力测试时同步形成 ADR、术语表等文档。 |
| 课程视频 | `hyperframes` | 视频、动画和动效项目的入口与渲染工作流。 |
| 课程视频 | `adobe-animate-fla-export` | 导出 FLA/XFL 动画帧，复用课程动画资产。 |
| 视觉资产 | `gpt-image-2` | 角色、场景、分镜、信息图等图像生成与编辑。 |
| 网页交付 | `web-video-presentation` | 将课程口播稿制作成可录屏的 16:9 网页视频演示。 |
| 网页交付 | `web-design-engineer` | 制作网页、原型、可视化和交互式课件页面。 |
| 内容交付 | `beautiful-article` | 将课程规则、审核报告等制作成可分享网页文章。 |
| 产品协作 | `product-plan-mindmap` | 将平台需求和方案整理为可讨论的交互式导图。 |

## 使用说明

- 每个技能文件夹内均保留原始 `SKILL.md` 和其关联资源。
- 安装时应保持文件夹名称不变，并将整个文件夹放入目标平台约定的 skills 根目录。
- 本包用于 AI 课件协作平台；人物风格、通用写作等非平台核心技能未收录。
