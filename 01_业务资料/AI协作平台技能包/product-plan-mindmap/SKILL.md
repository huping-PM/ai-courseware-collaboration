# 产品方案讨论导图

产出可本地打开的 HTML 导图、同源 Markdown 和可继续编辑的 JSON。沿用“左侧看结构、右侧看内容”的讨论方式；先解释业务问题，再展开解决方向。默认中文，可按项目改变名称、颜色与语言。

## 先确定讨论结构

- 以业务场景划分一级目录，通常收敛为 3–4 个；跨场景的运营、增值服务或品牌体验可以合并为一个方向。数量是参考，不强凑目录。
- 二级节点是具体场景或要解决的问题；标题简短，业务背景放在右侧详情，避免把整句话塞进节点。
- 每个二级节点先判断讨论类型，不能都写成 A/B/C 单选：
  - **方案比较**：核心问题 → 方案A/B/C… → 推荐结论。可以推荐一项或互补组合，在对应节点直接标“推荐”。
  - **协同模块**：核心问题 → 多个功能模块。各模块一起支撑业务，不写假选择、不强加推荐结论。需要时标数字优先级 1/2/3，用三种颜色区分。
  - **条件分支**：核心问题 → 不同外部条件下的处理方式。由政策、客户条件等决定的分支不硬做推荐。
- 方案与模块节点下不再增加功能子节点。核心功能模块及用途写在右侧详情，保持导图易扫读。

## 节点怎么写

**核心问题**：用一个连贯段落讲清“谁在什么业务过程里，为什么会遇到什么问题，造成什么影响”。不要把业务场景、重复原因、用户问题拆成三个重复段落。然后用“方案方向”说明后续方案共同要改变什么、为什么；不在此逐个介绍方案。

**候选方案**：依次说明产品形态、界面呈现、交互体验、优点、劣势、选择理由；按需加入必要约束。重点描述用户看见什么、点击后发生什么。内容制作方式只在相关时简述，不能代替产品形态。每个核心功能模块用 1–2 句话解释“是什么、解决什么”。不为凑数加入明显无意义的常规方案。

**推荐结论**：放最后。一句推荐及理由，再用每方案一句话比较优势和代价；避免重复整个方案。组合建议可放这里。只有用户确实讨论实施或验证时才加入这些内容。

**协同模块**：说明业务触发场景、模块作用、主要操作和结果，再列核心功能。优先级按依赖与价值决定，不能仅为数量平衡降级必需功能；若二级是完善体验，写明一级仍需具备哪些基本能力。未要求排期时不要自行推演成实施计划。

奖励、AI、个性化等抽象词必须落到具体场景。例如激励要说清何时获得、规则、奖励能兑换什么；AI要说清用户在哪提问、依据哪些内容回答、产出如何使用。不要套用任何特定行业规则，也不要把示例假设写成已确认事实。

## 生成或修改

1. 新建时读 [数据结构与示例](references/schema.md)，用 `assets/example.json` 起稿；保持讨论稿属性。用户提供的背景和已确认选择优先于模板。
2. 使用 `node scripts/build.cjs <方案.json> <输出目录>` 生成 `产品方案-交互导图.html`、`产品方案-讨论稿.md` 和 `方案数据.json`。图片以 JSON 所在目录为基准，由脚本复制到交付目录。不要手写另一份不同内容的 Markdown。
3. 已有生成稿时修改 JSON 后重建；覆盖需用 `--force`，只在本次授权更新该产物时使用。旧导图不符合本技能格式时先检查其数据与渲染结构，做有边界的增量编辑，不强行迁移或替换整个页面。
4. 用户说“先沟通”时只讨论；确认某节点后只改相关节点。改标题、排序、方案或推荐时同步详情和结论。不要回放此前已完成的修改，也不要因模板重置既有图片与交互。

## 呈现约定

- 默认暖白背景、深绿色正文与选中态、棕色连接强调。沿用现有项目风格时不强制改色。
- 左侧按“总标题 → 一级方向 → 二级议题 → 方案/模块”展示，点击节点更新右侧。右侧宽度可由中间分隔条左右拖动；支持键盘调宽，小屏上下布局。
- 地图区隐藏滚动条但保留滚动能力。顶部保留导图、展开全文、收起全文；默认不加搜索、打印或文字下载按钮。
- 效果图放在“产品形态”说明处，以缩略图进入完整弹窗。多个版本放同组，点击任一缩略图一起展示；图片等高、保持比例，不拉伸。允许没有图，不要附不相关占位图。
- 需要新效果图时使用可用的图像或设计工具；生成内容应对应该方案实际形态。工具不可用就明确说明，不谎称已经写入设计平台。除非用户要求，不替换已认可的旧图。
- 推荐标签与数字优先级保持不同语义；优先级可选，按业务需要使用。统计从数据计算，不能保留模板或旧项目的固定数量。

## 交付前检查

在浏览器中实际打开生成稿：检查不同方向与节点切换、右侧模块解释、推荐及优先级、全文模式、分栏拖动与窄屏布局。存在图片时检查加载与弹窗，尤其多图等高展示。确认没有旧项目名称、硬编码统计、丢失图片或脚本错误。

完成后给出可打开的文件链接和简短变更说明。讨论内容仍有待定条件就明确标识，不宣称这是研发验收规格。
