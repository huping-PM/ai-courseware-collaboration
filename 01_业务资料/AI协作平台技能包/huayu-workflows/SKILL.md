## Operating rules

- Treat the existing source folders as read-only unless the user expressly requests a change in that project.
- Keep output location separate from source research materials and preserve the source project's naming/filing conventions.
- When the request spans multiple domains, identify the primary deliverable first; consult the secondary source only for the needed context.
- If a source path is unavailable, state that clearly and proceed only with user-provided material or general best practice.
