# 会议纪要与录音原文

本目录统一保存本项目会议录音转写原文，以及后续按需整理的会议纪要。建立日期：2026-09-14；依据：用户要求统一归档与命名。

## 保存与命名

- 录音转写原文：`主题_YYYY-MM-DD_HHmm_原文.md`，例如 `AI课件协作平台需求讨论_2026-09-14_1337_原文.md`。
- 整理后的纪要：使用相同主题和会议时间，将结尾改为 `_纪要.md`，在正文标明草稿或确认状态，并链接原文。
- 主题概括会议实际讨论内容，避免使用“标准录音”“新建文档”等无辨识度名称。
- 日期与时间取自原文明确标注或用户提供的信息，索引注明依据；不得使用下载、文件修改或归档时间代替会议时间。仅有日期时省略 `_HHmm`；日期未知时使用 `主题_时间待确认_原文.md`，确认后更名并同步引用。
- 同主题同时间有多份独立录音时，在类型前加 `_01`、`_02`；重复文件先核对内容，不重复收录，不覆盖已有文件。
- 原文按源文件原样复制，保留发言顺序、时间戳和转写错误，不在原文中补标题、改写或添加结论。来源和说明写入本索引；校订或分析另存，并关联原文。
- 每次新增材料同步本索引和[资料索引](../资料索引.md)，记录来源、会议时间及依据、归档日期、阅读状态和关联产物。按[协作规范](../../00_项目管理/协作规范.md)更新受影响记录。
