# 通用提示词库（可直接套用）

## 1. 配音稿润色（edge-tts 输入稿）

本项目用逐句短句（每句 1~15 秒），标点规范、书面化、不口语化啰嗦。配音参数：

```
voice = "zh-CN-XiaoxiaoNeural"
rate  = "-5%"    # 略慢，适合政策解读
```

**逐句稿写作要点**：
- 每句是语义完整的一段，句末加句号/分号；分号也会被 TTS 读出明显停顿。
- 数字、年份、书名号《》、引号“ ”都要保留（TTS 能处理中文标点）。
- 一句话别超过 ~40 字，否则语速衬托下画面节奏难配。
- 每场首句是「小标题句」（如「二、强化产品源头管理。」），要单独成句，动画把它当标题卡处理。

## 2. 每场景构图提示词（喂给生成或自写 HTML 时的结构参考）

| 场景类型 | 构图 | 动效节奏 |
|---|---|---|
| 提出问题（3 个问题并列） | 左配图 + 右三张卡片（图标+标题+描述） | 三卡依次 4s 间隔弹出 |
| 时间线（演进） | 三级阶梯曲线 + 节点图标 | 曲线 SVG 逐段 draw，节点顺次弹 |
| 总括（六大板块） | 2×3 卡片网格 | 六卡 0.2s 间隔依次弹 |
| 原则（四项） | 2×2 卡片 | 四卡顺次弹 |
| 对比 + 分支 | 上半对比两卡 → 下半分支三卡 | 对比先入、箭头 draw、分支 hub 展开 |
| 三举措/三支柱/三主体 | 3 卡并列 | **严格按旁白三句对齐**（见 sync.md） |
| 三行展开（tag+说明） | 三横条，左 tag 右说明 | 每条 tag/说明分步入 |
| 小结 | 关键词胶囊 + 结论条 | 胶囊逐个 0.8s 弹，结论条最后 |

## 3. 配图生成提示词（ImageGen）

政策解读类配图要「扁平插画、无文字、淡蓝主调」，避免生成中文文字（会乱码）：

```
扁平风格商务插画，淡蓝色主色调(#EAF2F8 背景、#1F4E79 深蓝元素)，
无任何文字和字母，简洁几何图形，柔和圆角，
主题：{场景主题}，明亮、现代、专业，16:10 横幅构图
```

注意：
- **不要并行调 ImageGen**（output_dir 不可靠会互相覆盖），逐张串行。
- 输出后放到 `hf-full/assets/`，在 sceneNN.html 里用 `<img src="assets/xxx.png">` 引用。
- 配图按需（关键页即可），元素图标才要求每页必有。

## 4. 整体观感提示词（给视觉代理或自查）

```
检查要点：
1. 每页都有元素图标（淡蓝圆底 + 深蓝线条），配图页有合适插画。
2. 配色统一：淡蓝底、白卡片、深蓝标题、近黑正文。
3. 文字无溢出卡片、无基线重叠、无缺失居中。
4. 每页留底部字幕区（y≈820~920 不放正文）。
5. 卡片/标题/正文字号符合规范（标题 62~72px、卡片标题 38~44px、正文 25~34px）。
```
