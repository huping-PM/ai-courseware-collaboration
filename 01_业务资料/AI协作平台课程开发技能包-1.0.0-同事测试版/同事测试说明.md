# 同事测试说明

## 建议测试顺序

1. 用 `course-manuscript-generation` 输入课题、对象、已核实依据、不可承诺事项和场景选择，检查是否得到完整可录制口播稿；
2. 用 `course-manuscript-review` 审核该稿，检查是否拒绝“大纲式文稿”；
3. 用 `insurance-microcourse-scene-design` 读取通过版的导入，检查镜头是否逐条回链口播、是否遵守禁忌；
4. 用 `course-ppt-storyboard` 读取确认口播和场景卡，检查每页是否有来源口播段、屏幕文字是否未机械复述口播。

## 最小输入包

- 课题与对象；
- 一个具体判断问题；
- 已核实事实及来源；
- 待核实事项；
- 不得作出的承诺；
- 场景选择或“新建场景”说明；
- 角色、风格和制作限制。

## 通过标准

- N04 不是大纲，而是完整口播；
- N05 有明确审核结论且不越权重写；
- N06 的内容均能回链确认口播；
- 场景库只用于创作选择，不替代任务事实依据；
- 不出现可读保单、品牌、夸张金额、承诺性结论等禁忌内容。
