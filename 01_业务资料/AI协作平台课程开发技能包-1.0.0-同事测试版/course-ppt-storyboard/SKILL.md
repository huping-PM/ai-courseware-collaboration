# 课程脚本与分镜 1.0.0（同事测试版）

用于 N06-B。输入必须是 N05 确认的完整口播稿，将其逐段映射为 PPT/Web 页面、场景镜头和制作指令；不重新写课程内容。

## 先读什么

阅读 [来源清单](references/source-manifest.md)、[N06 脚本与分镜契约](references/storyboard-contract.md) 和 [验收清单](references/acceptance-checklist.md)。有情境导入时，先接收 `insurance-microcourse-scene-design` 的场景卡。

## 输出

按契约输出页面/分镜表：编号、来源口播段、时长、教学或叙事目的、画面、短屏幕文字、口播/对白、动画/转场、人物位置、素材/资产 ID、制作提示、风险、确认状态。

知识页一页一核心信息；屏幕只保留关键词、流程、对比或记忆口诀，口播解释条件、原因和边界。规则文字用可编辑后期图层；栗子精灵小结独立成页。

## 边界

每一页/镜必须有来源口播段。需要实质删改、新增或改变口播语义时退回 N05；镜头、版式、资产和动效问题留在 N06 修正。
