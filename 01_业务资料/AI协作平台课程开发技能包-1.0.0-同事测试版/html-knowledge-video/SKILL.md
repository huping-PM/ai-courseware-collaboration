# HTML知识动画制作

版本：1.0试用版，2026-09-21。源于用户批准的HTML动画规则及实际制作经验；新封装的技能尚未完成独立端到端回归。

## 任务入口

先识别是新课、续作、修改、导出还是诊断。检查已有项目、最新文件和用户确认记录；不把局部修改或导出重新变成全套需求访谈。明确说明使用本技能及当前阶段。

- 新课或续作：读 [workflow.md](references/workflow.md)，使用 [视频规格书](assets/video-spec-template.md)。
- 分镜、配图或画面修改：读 [content-to-visual.md](references/content-to-visual.md)，使用 [分镜模板](assets/storyboard-template.md)。
- 实际编写动画、配音、资源接入或导出：读 [technical-and-media.md](references/technical-and-media.md)，再读取目标环境可用的HyperFrames入口技能及其要求的相关规范。缺少依赖时说明限制，不假装已调用。
- 预览、验收、交付或成本记录：读 [quality-and-cost.md](references/quality-and-cost.md)，使用 [验收模板](assets/acceptance-template.md)。
- 需要追溯历史验证范围时才读 [evidence.md](references/evidence.md)。历史路径不是运行依赖。

## 不可丢失的用户偏好

1. 知识结构清晰优先。中文横屏微课；默认1920×1080、30fps、H.264/AAC MP4。6–8分钟是目标，不是填充时长；按实际口播确定成片。
2. 口播解释、画面组织。屏幕文字精简，但保留关键条件、限定与例外，不擅改已审核业务口径。
3. 不展示页码、场次编号、试制版、声线或制作说明等无关页脚。知识步骤编号不是页码；必要合规说明不属于可随意删除的装饰。
4. 按内容设计动作、结构图和必要图片；不能整片都是文字框，也不能机械地每页配一张图。中文关键标签、数字及准确关系用HTML/SVG表达。
5. 配音优先复用已获授权的合适音轨。需合成时沿用已接受的在线晓晓女声 `zh-CN-XiaoxiaoNeural`、语速 `-5%` 作为默认起点。不是原片晓辰，不是离线开源语音。不要悄悄换成本地生硬音色。
6. 默认无背景音乐、音效和烧录字幕；有新要求时覆盖。不能把旧课的具体时长、场数或配图数量当通用规则。
7. 保留原稿及Studio中的用户修改；写入前读最新文件，禁止盲目重跑生成器覆盖调整。新模型安装、付费服务、对外发布和新增上传不由本技能自动授权。
8. 用户要求导出时必须交付可用MP4，而不只给预览链接。技术验收与业务/合规审核分开，明确未验证项。

本技能规定工作方法和验收边界，不保证任何外部服务永久免费、特定单片成本或完全复刻第三方作品。用户当次明确要求优先于这里的默认风格。
