# N04–N06 验收清单

## N04 文稿

- [ ] 一个具体问题、至多 3 个知识点、预计 8–10 分钟；
- [ ] 每段为完整可录制口播，不是大纲；
- [ ] 导入 60–90 秒，只引题，具备触发、误解、矛盾、冻结问题和转场；
- [ ] 每个判断点已说清结论、条件、误区、服务动作、依据；
- [ ] 栗子精灵独立小结且不超过 150 字；
- [ ] 8 道题、答案、解析、依据完整；
- [ ] 关键事实来源可追溯，未核实内容未被写成结论。

## N05 审核

- [ ] 输出 P0–P3 问题单与明确结论：通过进入 N06 / 修改后复审 / 退回上游；
- [ ] 通过后锁定文案确认版及其来源版本；
- [ ] 未审核通过的大纲或草稿不能进入 N06。

## N06 分镜

- [ ] 每页/每镜回链来源口播段；
- [ ] 屏幕文字与口播分工明确，未机械重复；
- [ ] 场景资产、镜头或页面问题在 N06 修正；实质口播问题退 N05；
- [ ] 无可读保单、品牌、夸张金额、承诺性结论等禁忌内容；
- [ ] 文案、动画/制作负责人分别确认可用性。
