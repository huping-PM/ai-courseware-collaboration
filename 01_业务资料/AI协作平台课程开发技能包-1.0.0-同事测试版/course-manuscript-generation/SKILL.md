# 课程口播稿生成 1.0.0（同事测试版）

用于 N04。产出必须是完整、可直接录制的课程口播稿，不是大纲；不生成 PPT 页面、镜头或制作提示。

## 先读什么

1. 必读 [来源清单](references/source-manifest.md) 与 [课程结构与完整口播规则](references/course-structure-oral.md)。
2. 读取任务的需求单、依据包、场景选择信息和课程模板。具体事实以任务依据包为准。
3. 资料不足、来源冲突或关键结论未核验时，列出待补资料并退回 N01/N02/N03。

## 输入

课题、对象、核心问题、学习目标、已核实事实及来源、待核实事项、不可承诺事项、场景选择（或新建申请）、角色/风格限制。

## 输出

按“题目—对象—目标—核心结论—制作说明—场景演绎口播—知识讲解口播—栗子精灵小结口播—8 道题—编审说明与来源”完整输出。

场景约 60–90 秒，必须写完整叙述/旁白/对白，包含触发、误解、矛盾、冻结问题和转场。知识讲解以“先判断 A，再判断 B，最后核实 C”组织；每点在口播中讲清结论、条件、误区、服务动作和依据。小结由栗子精灵独立完成，不超过 150 字。

## 边界

可附关键词或信息呈现意图；不得写页面编号、镜号、机位、布局、动画、素材清单或生成提示词。完成后交 `course-manuscript-review`；只有 N05 通过版可进入 N06。
