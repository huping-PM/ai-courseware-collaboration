# 场景库索引与制作禁忌

## 选择方式

先按课题的核心误解、受众、是否需要对白暴露误解、画面动作需求与制作条件推荐场景。可选叙事版、V3 对话版或融合版；输出必须记录选择方式、理由和确认人。无适配场景时可以“新建”，但必须人工确认后进入制作。

## 共通场景骨架

日常铺垫 → 风险或认知冲突 → 现实压力/关键矛盾 → 冻结问题 → 课程收口。导入总时长 60–90 秒，N06 可按节奏弹性拆镜，不锁死镜头数量。

## 制作禁忌

- 不出现血腥、死亡/重症特写、极端事故、狗血哭戏或夸张表演；
- 不生成真实保险公司标识、可读保单、夸张金额、营销承诺；
- 政策类不特写公章或完整文号，仅以可编辑后期图层表示文件信息；
- 场景只提出问题，不写“当场获批、立即到账、必然赔付、必然适用”等结果；
- 所有事实结论回到任务依据包核验。
