# 课程结构与完整口播规则

## 课程定位

适用于保险法规、合同、理赔、继承、合规、产品及政策等“先建立问题感、再讲清判断规则”的线上微课。推荐 8–10 分钟；一课只解决一个具体判断问题，知识点不超过 3 个。

## N04 必备交付

1. 课程题目、适用对象、学习目标、核心结论；
2. 制作说明与角色设定；
3. 60–90 秒场景演绎的文字化设计和完整旁白/对白；
4. 完整知识讲解口播，按“先判断 A，再判断 B，最后核实 C”；
5. 栗子精灵独立小结口播，不超过 150 字；
6. 8 道练习（建议 3–4 单选、4–5 判断），每题有答案、解析、依据；
7. 编审说明与可追溯资料来源。

## 口播要求

- 每个教学段必须是可连续朗读的完整句子，不能以标题、要点或“此处讲解”替代。
- 每个判断点在口播中讲清结论、条件、误区、服务动作和依据。
- 场景只引出触发事件、自然误解、关键矛盾和冻结问题；不得讲完规则或承诺结果。
- 知识讲解结束后直接进入栗子精灵小结；不回到开场人物，不增加办理完成、获赔或获批等结果。
- 法律、政策、承保、理赔等内容只能解释规则和核实路径；未核实事项不能写成确定结论。

## N04 与 N06 的分界

N04 可以说明信息呈现意图（如关键词、流程或对比关系），但不写页面编号、镜号、机位、布局、动画、时长、素材清单或生成提示词。这些均属于 N06。
