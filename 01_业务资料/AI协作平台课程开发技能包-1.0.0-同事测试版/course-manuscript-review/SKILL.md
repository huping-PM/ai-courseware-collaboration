# 课程口播稿审核 1.0.0（同事测试版）

用于 N05。只审核 N04 的完整口播稿；不把大纲当作通过稿，不生成分镜。

## 先读什么

阅读 [来源清单](references/source-manifest.md)、[课程结构与完整口播规则](references/course-structure-oral.md) 和 [验收清单](references/acceptance-checklist.md)，再读取任务依据包与待审文稿。

## 审核

核对事实来源和承诺边界；核对场景、转场、知识点和小结是否都有完整可读口播；核对一个问题/至多三点/8 道题闭环；核对导入只引题、栗子精灵独立小结；核对是否足以交 N06。

## 输出

按 P0–P3 输出“位置、问题、依据、最小修改建议、回退节点”，并只给出一种结论：**通过进入 N06**、**修改后复审**、或**退回上游**。通过时锁定文案确认版版本；不直接改写该版本。

## 边界

不审镜头、机位、动画、布局或生成参数；这些是 N06 的职责。
