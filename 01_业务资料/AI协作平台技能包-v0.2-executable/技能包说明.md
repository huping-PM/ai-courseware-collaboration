# 内容视频生产技能包

## 定位

本包仅保留“内容资料 → 可审核课程文稿 → 分镜 → 视觉/动画视频”的生产能力，以及保证事实可追溯所需的调研能力。它不包含通用商业方案、产品导图、网页文章或与内容视频生产无直接关系的工作流。

## 已收录技能（11 个）

| 阶段 | 技能 | 用途 |
| --- | --- | --- |
| 资料与依据 | `agent-reach` | 调研外部资料并沉淀可引用结论。 |
| N04 | `course-manuscript-generation` | 生成或受控修订可审核的课程口播稿。 |
| N04.5 | `course-manuscript-validation` | 拦截角色、结构、题目、来源与模板残留等硬错误。 |
| N05 | `course-manuscript-review` | 审核内容、来源、口播与情境导入。 |
| N06 | `insurance-microcourse-scene-design` | 将锁定的情境导入细化为资产和镜头卡。 |
| N06 | `course-ppt-storyboard` | 将锁定口播映射为页面、分镜和制作说明。 |
| 视频 | `html-knowledge-video` | 制作 HTML 知识动画视频并验收导出。 |
| 视频 | `hyperframes` | 动画、视频和渲染工作流入口。 |
| 视频 | `adobe-animate-fla-export` | 导出/复用 FLA、XFL 动画资产。 |
| 视觉资产 | `gpt-image-2` | 生成和编辑人物、场景、分镜与信息图。 |
| 网页视频 | `web-video-presentation` | 将课程口播制作成可录屏的 16:9 网页视频演示。 |

## 平台接入

- 每个技能文件夹保留 `SKILL.md`；有界面的 Skill 使用 `agents/openai.yaml`。
- 平台必须读取 `skills-registry.yaml` 和 `workflows/course-manuscript-production.yaml`，按状态机执行 N04 → N04.5 → N05 → 锁版 → N06。
- `contracts/` 中提供任务卡与产物清单示例。上下游应传递结构化状态、版本与证据 ID，而不是只拼接聊天文本。
- 草稿、P0 校验失败的产物、未批准版本不得进入 N06 或发布。
