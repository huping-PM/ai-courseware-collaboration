# 内容驱动画面设计

## 视觉基线

已接受的知识课风格可复用：暖纸色背景#EEE9E1、浅纸面#F7F2EA、酒红#7B2531、深墨#2A2020、金棕#9B7040。中文衬线标题配清晰正文，确保本地字体与授权；这是可替换风格，不是所有课程强制配色。

留出安全边距，优先读得清；不要用大量英文小字、装饰档案编号或固定页脚填空。长口播不逐字塞进画面。按讲解出现关键点，给阅读与理解留时间。

## 内容关系到视觉

| 内容 | 可选视觉 | 动作应说明什么 |
|---|---|---|
| 主观判断与证据比较 | 天平、证据堆、划除错误标签 | 从失衡判断转向证据支持；不暗示不存在的定量结果 |
| 对话与复盘 | 人物对话、录音机、波形、游标 | 正在讲哪句、停在哪里、发现什么问题 |
| 流程、准备、跟进 | 路径、工具包、日历、清单 | 先后顺序、必备条件、下一步动作 |
| 分类、边界、例外 | 分支图、分区、对照对象 | 哪些归类、哪里不适用；标签必须准确 |
| 数据与转化 | 漏斗、条形图、节点连线 | 数量关系或断点；无依据数字不得编造 |
| 实际物件、客户场景 | 必要插图、物件切图 | 帮助识别情境，不代替关系解释 |

按本场语义选择，不为了复用天平或波形硬套。波形无真实音频分析时标作示意，不冒充真实录音数据。卡片可用于局部信息组织，但不能成为整片唯一视觉。

## 图片策略

决定“这张图帮助理解什么”后再生成。人物沟通、资料包、面谈场景适合插图；精确流程、制度边界、收益条件应优先HTML/SVG。保持统一色调与风格，避免生成图中的中文关键文字，准确标签后置绘制。

生成提示包含：讲解目的、主体、构图留白、画幅、风格、配色，以及无品牌、无客户隐私、无虚构批准印章/收益数字。用户提供品牌资料且允许使用时再采用真实品牌元素。

优先检查已配置、可用且授权的图片工具。开源界面、开放权重、在线付费API、原生图像工具分别说明，不混称“开源免费”。新增大型模型下载、服务注册或付费调用需要相应权限。没有工具时交付提示词并说明未生成，不用占位符冒充成品。

新增图片生成遵循可用图像技能与原生工具要求。保存原图、使用尺寸、来源/提示摘要与所在场景；实际预览和MP4都要核验图片显示。
