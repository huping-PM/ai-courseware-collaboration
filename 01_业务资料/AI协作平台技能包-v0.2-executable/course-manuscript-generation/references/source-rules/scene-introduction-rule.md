# 保险微课 60 至 90 秒情景导入规范

**版本：** 审核优化版 v1.0  
**适用：** 人身险、财产险、政策文件类保险微课  
**定位：** 课程正文前的情境导入，不替代正文知识讲解、保险方案推荐、理赔判断或政策解读。

## 一 审核结论与保留范围

来源文件中的“人身险 6 套 + 财产险 5 套 + 政策类 3 套”共 14 个场景，均保留为场景资产库。保留其“日常铺垫 - 风险触发 - 压力或疑问 - 课程收口”的叙事骨架、写实克制调性、行业禁忌及分类框架。

原 PDF 同时收录“叙事版”和“V3 对话版”两套同题脚本。两版均保留，作为同一场景资产的两种可选表达模板：系统可根据课程内容给出推荐，课程负责人也可人工直接选择。每次使用必须记录所选版本、选择理由和确认人，避免无标记地混用两套脚本。

## 二 导入的边界

1. 导入只提出问题，不给出产品承保、责任归属、理赔金额或政策适用的确定结论。
2. “保险可以覆盖”“理赔款稳定现金流”“全部由谁承担”等表述，统一改为“保障范围、责任承担和理赔条件需结合合同、事实与适用规则核实”。
3. 不演绎真实公司、真实客户、真实保单、可读的检查结论、理赔决定、公章、文号或金额。
4. 对疾病、意外、灾害、公众责任等主题，只呈现克制的风险信号；不使用死亡、重症、血腥、惊悚、猛烈事故或哀嚎画面。
5. 政策类课题必须先经依据包核验：发文机关、现行版本、适用主体和地方差异未确认前，只能写成“需核实是否适用”。
6. 课程收口必须转为问题，交给正文回答；不得在导入中变成营销话术或强行推险。

## 三 时长与叙事结构

总时长 60 至 90 秒，镜头数量按叙事需要决定。建议采用下列时长预算：

| 段落 | 目标时长 | 任务 | 禁止事项 |
| --- | --- | --- | --- |
| 日常铺垫 | 12 至 20 秒 | 呈现人物的自然判断或旧认知 | 直接讲条款、夸张台词 |
| 风险触发 | 12 至 20 秒 | 出现一个风险信号或关键信息 | 演成事故大片、直接定责 |
| 压力或疑问 | 18 至 30 秒 | 呈现现实压力，留下待判断问题 | 给出理赔结果或产品承诺 |
| 课程收口 | 10 至 15 秒 | 用问题转入正文知识讲解 | 回到人物继续讲规则 |

可省略“压力”中的具体损失画面，改用材料、通知、账本或人物停顿表达。任何单一镜头只承担一个主要动作或信息点。

## 四 情景导入脚本的统一字段

每条脚本统一使用以下字段，缺一项不得进入镜头制作：

```text
场景 ID：P01 - P14
课程课题与适配知识点：
已核实依据与版本：
教学边界：可讲 / 待核实 / 不可承诺
叙事类型：痛点暴击 / 认知更新 / 双线对比 / 细节沉浸 / 悬念钩子 / 知识闭环
日常铺垫：场景、人物、道具、一个自然对话或动作
风险触发：风险信号、画面边界
压力或疑问：人物问题，不给结论
课程收口：转入正文的一个问题
表达版本：叙事版 / V3 对话版 / 经确认的融合版
选择方式：AI 推荐后确认 / 人工选择
选择依据与确认：主题、受众或制作原因；确认人
角色资产 ID、场景资产 ID、道具资产 ID：
镜头卡：镜号、时长、景别、机位、人物动作、旁白、屏幕文字、禁止元素
Seedance 参数与候选版本：
审核状态和确认人：
```

## 五 Seedance 逐镜生成规范

### 1. 生成顺序

1. 先锁定角色、场景、道具参考资产；
2. 从脚本拆成单镜头镜头卡；
3. 每镜生成 2 至 4 个低成本预览；
4. 人工选择后再重生、延长或衔接；
5. 只有通过验收的镜头才能进入合成。

不得用一条长提示词直接生成完整 60 至 90 秒导入。口型、文件文字、账单数字、保单内容和政策条款均由配音、字幕或可编辑后期图层完成，不作为模型生成验收标准。

### 2. 通用镜头提示词模板

```text
16:9 保险培训微课单镜头，时长 [X] 秒。
参考资产：角色 [角色 ID]，场景 [场景 ID]，道具 [道具 ID]。
画面风格：写实生活化，轻微电影质感，自然真实光影，人物表演克制。
镜头： [全景/中景/近景]，[固定/缓慢推近/缓慢横移]。
人物位置与动作： [一个主要动作]；表情 [克制描述]。
画面重点： [风险信号或关键道具]。
禁止：新增人物、人物外观变化、可读的证件或保单文字、公司标识、公章文号、金额、血腥重症、夸张哭戏、危险事故特写、突兀跳切、水印。
```

### 3. 验收标准

每镜按以下五项通过才可锁定：人物与参考资产一致；动作和机位符合镜头卡；无错误文字或违规元素；情绪和行业调性克制；可与前后镜头衔接。失败镜头只退回当前镜头、资产或分镜，不影响已确认镜头。

## 六 14 个场景资产库

| ID | 保留主题 | 执行时的最小优化 |
| --- | --- | --- |
| P01 | 中青年职场 医疗与收入中断 | 用“异常检查/住院建议”代替明确疾病诊断；不承诺医疗险与重疾险的具体责任分工 |
| P02 | 灵活就业 社保与商业保障 | 不写“社保报销上限”等未核实绝对表述，改为提示核实保障边界与自费、误工风险 |
| P03 | 育儿家庭 家庭责任 | 删除“理赔款稳住现金流”等既定结果，双线对比只呈现保障规划是否完善 |
| P04 | 日常个体 小额意外 | 不把“低成本意外险”写成统一推荐，改为“可了解相关保障范围与条件” |
| P05 | 家庭支柱 健康告知与理赔 | 将“理赔异常”改为“需要补充核实材料或出现疑问”；不暗示理赔受阻的原因已经确定 |
| P06 | 养老退休 现金流与照护 | 保留温和反思，不使用“每个人必然失能”等确定性表达 |
| P07 | 家庭财产 家财险 | 漏水与损失可保留；收口改为核实承保范围、责任和免责事项 |
| P08 | 生产建设 建工险企财险 | 灾害仅以照片、通知或受损线索呈现；不先写“专门覆盖所有损失” |
| P09 | 出行物流 车险货运险 | 区分承运责任、车辆责任和保险责任，导入不预判任何一方赔付 |
| P10 | 农业 农险 | 保留天气风险；将“收成全没了”改为“作物受损、收成面临压力” |
| P11 | 公众经营 责任险 | 顾客滑倒不等于经营者必然担责；仅呈现索赔或责任疑问，正文再解释条件 |
| P12 | 安责险政策 | 适用主体和强制投保范围必须以现行权威政策核验；未核验时只提出“是否在适用范围内” |
| P13 | 灾害保险服务体系政策 | 保留“防灾减损 - 应急服务 - 损失补偿”框架，但在正文核验政策原文和适用范围 |
| P14 | 基层服务监管规范 | 不把“检查反馈”演成既成处罚事实；改为发现留痕缺口、需对照规范整改 |

## 七 纳入课程开发流程

| 课程节点 | 新增或替换的产物 | 人工确认 |
| --- | --- | --- |
| N02 依据核验 | 导入事实边界表 | 专业人员确认政策、产品与案例边界 |
| N03 模板选择 | 选择 P01 - P14 或新建场景资产；同时选择叙事版或 V3 对话版 | AI 可按主题、受众和制作条件推荐；课程负责人可人工选择并确认 |
| N04 课程文案 | 60 至 90 秒导入脚本，采用本规范字段 | 内容负责人确认课程问题与收口 |
| N06 脚本分镜 | 每镜镜头卡、角色/场景/道具资产 ID | 动画负责人确认可制作性 |
| N07 视觉资产 | 经确认的参考图与资产版本 | 角色连续性与版权检查 |
| N08 Seedance 镜头 | 候选镜头、参数、验收标签 | 逐镜确认后合成 |
| N11 成片审核 | 导入与正文事实边界一致性检查 | 最终验收 |

## 八 课程正文衔接规则

导入结束后，必须立即转入“问题页或知识讲解页”。正文负责定义、条件、规则、案例和行动建议；结尾再由栗子精灵独立总结，不回到导入人物场景。导入、正文和小结分别承担“建立问题 - 解释问题 - 提炼记忆”，不得互相替代。

## 九 审核清单

- [ ] 已明确选择叙事版、V3 对话版或经确认的融合版，并记录选择理由
- [ ] 场景时长在 60 至 90 秒，收口明确转入正文问题
- [ ] 未出现承保、理赔、定责、政策适用的确定性结论
- [ ] 已为每条政策或产品结论绑定已核实依据
- [ ] 每镜都有动作、机位、参考资产和禁止元素
- [ ] 未出现可读证件、保单、金额、公章文号、公司标识或未经授权人物
- [ ] 不含血腥、重症、死亡、恐吓和过度营销表达
- [ ] 成片导入与正文、栗子精灵小结无事实冲突
