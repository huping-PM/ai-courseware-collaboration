# 内容协作智能体 UI 设计方案

版本：v0.3｜日期：2026-09-28｜状态：按用户最新要求收敛并细化，原型待评审。

[交互原型](../04_原型与说明/AI协作工作台-风格探索/index.html?style=b&page=workspace) · [原型图与核验](../06_交付与验证/AI协作工作台UI风格方案/index.html)

## 1. 当前范围

本方案只保留**内容协作智能体**模块，沿用B灵感工作室的工作区布局与视觉语言。资源管理和智能体配置不再作为本方案的页面或导航；协作输入区内的参考资料、技能选择及对话沉淀技能仍属于创作流程。此收敛针对本次设计交付，不据此删除项目需求管理中已记录的其他业务需求。

依据：用户最新四项明确修正，记录D056；现有Markdown编辑、成果保存、资源/技能引用与项目权限仍按迭代需求继承。D054中把左侧视为业务任务列表的解释由本轮会话记录要求替代。

## 2. 页面布局

- 单层顶部栏：品牌/模块名称、必要的项目上下文和用户入口。删除原第二层面包屑栏，不留空白占位。
- 左侧会话记录：约220px宽，紧凑单行条目，标题旁提供独立SVG加号按钮新增会话。
- 中央画布：文档、图片、视频切换；工具条保留成果名称和当前可用操作。
- 底部成果条：目标高度约94px，三类筛选竖排，文档/图片/视频横向展示；媒体缩略图约60px高。
- 右侧智能体对话：1440px桌面下约400px宽，比上一稿约330px加宽；消息区独立滚动、输入固定在底部。

尺寸为本轮原型布局规格，随容器适配；不把1440px视为真实系统唯一窗口尺寸。

## 3. 会话记录与新增

| 元素/操作 | 规则 |
|---|---|
| 条目 | 单行显示会话名称，过长截断并可查看完整名称；状态图标紧贴名称所在行右侧 |
| 进行中 | 使用环形/时钟SVG；悬停和可访问名称为“进行中” |
| 已完成 | 使用勾选SVG；悬停和可访问名称为“已完成” |
| 状态含义 | 指会话中的AI执行状态，不等同业务任务的待审核/审核通过；未发起执行的空会话可不显示状态图标，不新增第三状态文案 |
| 新增会话 | 点击标题旁加号，输入名称或使用默认名称，创建独立空会话并选中；原会话保留 |
| 切换 | 同步会话消息、输入草稿、引用与成果，避免沿用上一会话成果；筛选条件与选中成果随会话保留 |
| 未保存内容 | 新建、切换或离开时提供保存后继续、放弃改动、继续编辑；取消不丢失输入 |
| 权限 | 历史记录可见范围沿项目及会话权限，不新增“我的业务任务”授权语义；本地演示不证明服务端隔离 |

会话记录不提供管理员的业务任务分配、审核或业务完成动作。真实执行的终态、失败恢复与后台通知仍需结合既有处理记录需求深化，本轮不通过新增会话伪造业务完成。

## 4. 紧凑成果条

| 类型 | 呈现 |
|---|---|
| 文档 | 文档SVG图标＋文件名称；名称截断时可查看完整名称 |
| 图片 | 仅缩略图，文件名通过提示和可访问名称提供 |
| 视频 | 首帧缩略图，可叠加小播放标识；原型采用首帧示意 |

左侧保留文档、图片、视频三个竖排筛选按钮，每类独立SVG图标；默认全部。点击一类仅显示该类，点击另一类切换筛选，再点当前类型恢复全部。筛选只影响清单，不自动切换画布。具体成果点击后才切换预览；未保存文稿先处理草稿。无成果或筛选无结果显示清楚空态。

压缩容器留白和卡片高度，保留可点击面积、选中边框及横向滚动。图片、视频不能启用Markdown编辑保存；返回文档后恢复可用操作。保存版本、保存到资源库与业务审核仍为不同动作。

## 5. 对话与内容操作

加宽后保持对话信息层级及输入习惯：Enter发送、Shift+Enter换行，中文输入法组合期间不发送。参考资料和技能在输入区选择；对话经验先形成可读草稿，经人工确认保存项目技能。AI识别媒体意图的真实服务由既有需求约束，本原型只演示反馈。

## 6. 验收与边界

1. 当前预览只出现内容协作智能体，不再展示资源管理/智能体配置导航，旧B模块链接回到协作页面。
2. 第二层面包屑不存在，主工作区直接位于单层顶栏下。
3. 会话名称和两类状态图标在同一行；新增按钮可创建并选中独立空会话。
4. 成果条高度约94px、三类筛选竖排可取消；对话约400px；1440×900无页面横向溢出。
5. 切换、新增保持草稿保护、会话内容隔离与原成果筛选行为。

当前状态：可审核本地原型；真实AI调用、跨设备存储、权限后端、视频首帧抽取和全量异常状态不由本次UI演示证明。原有Figma和正式业务入口未发布替换。
