维护日期：2026-09-14。版本：v0.2。状态：待评审，7张截图已分析，主要页面及6类代表性弹窗已进行实页取样。具体覆盖见[核验记录](页面与组件核验记录.md)。

用途：后续为本项目制作同风格页面原型时，先读取本文件，按页面所属类型复用布局和组件。用户已要求以原有截图为风格依据；这不等于确认截图系统的全部业务能力、技术框架或首版范围。原始截图保持不变。

## 1. 证据与读法

- **观察**：截图直接可见的外观、文字或状态。
- **像素取样**：原图中的实际 RGB 色值；不等同于已读取源代码中的 CSS 变量。
- **估测**：按原图位置估算的尺寸与字号。截图像素不保证等于 CSS 像素，浏览器缩放和设备像素比尚未核验。
- **原型约定**：为使后续产出一致而建议采用的明确值或行为，不冒充原系统规则。

第2—6节保留截图基线，布局尺寸以原图为基准，尺寸为估测、色板为像素取样。第10节为后续浏览器DOM与计算样式实测，其明确核验的属性优先；未核验属性仍按截图估测。DOM中可见el-button、el-dialog等组件类名，但没有读取项目依赖清单，不认定具体组件库版本。

## 2. 风格结论与页面族

整体为浅色桌面管理系统：白色工作面、极浅灰背景、蓝色操作、小圆角、细边框、紧凑控件、大面积留白。信息主要通过导航层级、表格和表单组织。后台内容页不额外插入大标题、说明横幅或统计卡片。

| 页面族 | 参考 | 应保留的特征 |

| B 项目入口与设置 | S08—S10 | 无左侧导航；入口卡片或居中设置区；主蓝 #409EFF |

## 4. 页面骨架与位置

### A：资源／课程后台

以1918宽原图为定位基准：

- 侧栏宽约265，全高白底。系统名称左距约32；一级菜单左图标约24，文字约48；子菜单进一步缩进约20。一级行高约56，课程子项约50。
- 顶栏位于侧栏右侧，高约56—60；左侧折叠图标与面包屑，右侧通知、头像、姓名及下拉箭头。面包屑约14号字。
- 页签栏高约50；活动页签浅蓝底、蓝字、图标和关闭符号。未选中项白底；右端有视图入口图标。不要把页签做成深色实心按钮。
- 主面板起点约 x=275、y=116—120；外间隙约10，内侧常规留白约24。右上可能有全屏入口，S05可见。
- S05 工具栏约 y=174，表格约 y=226；表头约48高，数据行约51高。稀疏数据仍保留较高表格工作区，分页靠右下。
- S06/S07 内容面板内分为分类树与列表。分类侧从 x≈299 至分隔线 x≈638，列表从 x≈655 开始；分类区域约340宽，表单工具栏右侧距列表左边约15。
- 资源查询标签在输入框上方；查询栏、右侧批量按钮在同一水平带，表格顶点约 y=247—251。资源行约61高，图片表头因换行约61高，文件表头约40高。

**原型布局约定：** 使用固定侧栏宽＋弹性主区，资源树约340宽；中间表格独立横向滚动，操作列在右侧固定。不要把整个1918宽画面等比压缩来适配较窄窗口。精确的滚动容器归属仍待实页核验。

### B1：项目入口

- 白色主面板距四边约10，左内容起点约34；顶部左“项目管理”、右头像姓名。
- 第二行为“我参与的／全部项目”灰底分段选择，右侧新建项目和网格／列表切换。
- 卡片从左侧顺序排布，截图一张约354×213，接近5:3；圆角约20，封面铺满。标题与说明在左上，蓝色类型标签在右上，三个小图标操作在右下。
- 图标中的锁形、齿轮、垃圾桶仅可确认外形；具体行为及权限不能从外形确定。
- 新建项目按钮约96×40。稀疏卡片不居中、不拉满整行、不补造统计内容。

### B2：项目设置

- 没有后台侧栏和多页面页签栏。左上面包屑；中央约888宽设置区，起点 x≈516。顶部“基本信息／成员管理”使用文字页签＋蓝色底线。
- 基本信息标签列约120宽；输入区从 x≈644 到1396，约752宽。标签与输入框左侧关系固定，表单按约50的纵向节奏排布。
- 文本输入高32；说明文本域约94高。必填星号红色；计数在输入框右侧／文本域右下；禁用编号灰底。
- 项目类型为横排多选项。截图可见多个选中项，不能反推互斥、最少选中数量或联动规则。
- 封面预览约300×180，与截图提示一致；上传按钮在预览上方。提示原文包含“建议尺寸300*180px，JPG、PNG格式，大小不超过1M”，该限制仅为S10可见规则，不自动套用到资源上传。
- 保存设置与取消位于表单右下，按钮高32。

### C：登录

- 1920×911截图中卡片约480×600，x≈720、y≈136；水平居中、垂直略偏上，圆角约10，浅边框与轻阴影。
- 顶部分段登录方式与语言入口；中部品牌图标、20左右粗标题和辅助说明；下方二维码与头像授权块并排，各约170×170。
- 复选项位于两块下方，再下方是账号入口；协议与版权位于页面底部。
- 原型不得复用有效二维码或真实人员头像授权信息。登录机制、自动登录及免密规则属于待确认内容。

## 6. 未展示状态与新增页面的补齐方式

静态截图只证明当前可见状态，不证明点击后的流程。以下是供可操作原型采用的**建议**，不作为原系统事实：

- 悬停保持同色系轻微强调；键盘聚焦用清晰描边；禁用同时改变样式并阻止触发，避免只把字变灰。
- 原截图未展示弹窗与空列表，现已由第10节补证。删除确认、加载、校验错误、上传进度及失败重试仍未体验，后续按需求补充，不声称与原系统一致。
- 常规表单弹窗优先复用第10节实测的600px类型；小分类表单使用500px类型。未展示的新弹窗按内容选择已有类型并标注原型建议，不再沿用早期640px估测值。
- 新列表默认延续A的密度与框架；新增表单沿用B的标签、控件和动作层级，但是否使用独立页或弹窗由任务确定。
- 原型建议在较窄桌面窗口保持控件尺寸、允许工具栏换行、表格横向滚动；没有移动端证据，不声称响应式规则已还原。
- 新原型提高封面文字可读性、避免分页裁切时，应标为有意优化；对照复刻时不能悄悄改变原版布局。图片原图已有文字压背景、窄列换行和截断，这些现象不必升级为新页面的强制标准。

## 8. 原型一致性检查

1. 先选页面族，检查主蓝、危险色、背景色；同一页面族无随意替换。
2. 以同等视口对照对应截图；先看侧栏、顶栏、页签、内容起点，再看组件，避免只比按钮颜色。
3. 常规控件32高，圆角4；导航、表格、项目卡片按各自尺度，不使用统一大圆角。
4. 字体层级、文本对齐、标签位置、表格密度和留白接近参考；不为了填满画面添加需求外内容。
5. 资源树、操作栏、表格固定列和分页不重叠；缩窄窗口不导致操作丢失。
6. 高保真原型保留对应表头、空值、缩略图、状态和行操作的视觉模式；数据内容由当前需求提供。
7. 交互原型核验已实现的导航、查询、切换、保存及取消；未实现的操作明确标注，不用静态截图证明行为有效。
8. 交付时注明依据截图、视口大小、规范版本、原型建议及与原版的有意差异；文档完成不等于用户确认或系统实现。
