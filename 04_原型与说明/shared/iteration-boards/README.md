# 迭代功能状态画板源

日期：2026-09-28。依据：[迭代功能设计v0.1](../../../03_功能设计/AI课件协作平台-迭代功能设计.md)及其上游需求v0.3。用途：按PG11、PG13、PG18、PG19和AUTH状态生成本轮原型图，供业务评审。

- [统一图文预览](../../../06_交付与验证/迭代需求原型预览/原型图与说明.html)
- [状态画板入口](board.html?state=PG19-S01)
- `workspace.js/css`承接PG11；`management.js/css`承接技能、任务和权限；`core.js/board.js/board.css`提供共用外壳与状态切换。
- `capture.cjs`使用本机Edge导出纯页面和带右侧说明的PNG；`截图核验.json`及`状态清单.json`保存在交付目录。

框架依据为[系统设计规范第10节](../../系统设计规范.md)、现有PG11内容协作状态原型、PG13智能体配置原型及共用base.css。保留266px侧栏、60px顶栏、32px控件、14px文字和既有主蓝；在同一框架中增加任务导航、编辑/审核等本次需求状态。状态编号用于映射原模块，画板源不建立新的业务导航入口。

本轮交付为原型图及状态切换演示，不替代既有完整HTML原型、Figma节点或真实服务。点击可演示的状态切换与局部输入不代表后端权限、模型生成、版本存储和统计已实现。PNG中的媒体画面为课程示意素材。

图旁说明来自状态数据，每页提供触发、结果和按功能组织的规则；在线预览可编辑并保存本地草稿或下载说明HTML。业务规则变动应先维护需求/功能设计，再更新画板与说明；不把浏览器本地修改自动反写成已确认共识。
