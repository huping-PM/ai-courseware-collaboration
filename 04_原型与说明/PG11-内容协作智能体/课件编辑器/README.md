## 本地维护

业务画面维护在editor.html/css/js；旁注主本维护在03目录，运行build-notes.cjs同步notes-data.js和图片索引。review.html将原型置于独立画布内，说明在画布之外；本地说明草稿不写回主本。下载图文HTML将当前状态原图与当前说明嵌入文件，便于线下分享。

capture.cjs在临时本机服务中导出1920×1080原型图和2352×1080图文图，并记录布局与脚本错误。preview-server.cjs可在127.0.0.1:8786提供本机预览，不是局域网发布或开机服务。

工程示例使用独立浏览器存储，不改其他原型数据。AI生成、视频导出、审核以及服务端隔离均不能由本原型代替实现；演示能力与静态状态的实际区分见交付记录。
