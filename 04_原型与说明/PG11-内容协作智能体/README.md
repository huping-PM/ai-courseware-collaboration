## 操作路径与覆盖

1. 新建对话：点击建议句仅填入草稿；输入1—5000字，删除右下快捷键说明，空白或只有依据不能发送，Enter发送、Shift+Enter换行，中文输入法选词不发送。
2. 选择依据：资源按文档、图片、音频、视频跨类型多选；技能多选，停用项不可选；按D019取消提示词选择入口及弹窗。弹窗查询、重置、取消、确定均可操作。输入区左侧仅保留选择资源、选择技能；右侧模型下拉替代发送按钮和字数提示（D020），Enter发送，Shift+Enter换行；原有历史消息中的依据记录仍保留。
3. 提交要求：先展示内容安排文档及人工确认；点击查看在右侧打开文档，确认并继续后展示图片与视频。确认前发送修改意见会新增文档供再次确认。输入过短时先要求补充信息；后续回复继承原依据。
4. 成果查看：文档只读；图片25%—200%缩放、100%和适应窗口；视频使用浏览器原生播放、进度、音量和全屏。切换内容、切换会话、关闭成果区会暂停视频。关闭后点击对应成果卡片重新打开；取消右上统一查看成果按钮。
5. 对话反馈：围绕此内容提问把成果作为独立标签加入草稿；发送后新增修改稿，保留原稿。原型使用固定内容和媒体演示反馈关系，未实现语义编辑。
6. 失败处理：部分成功保留文档，视频失败显示原因；重试使用原请求依据、仅恢复失败成果，保留下一条草稿。依据失效阻止发送，必须移除或重新选择；预览失败可重新加载。
7. 历史与隔离：会话绑定项目，使用浏览器本地存储恢复；未发送空会话不进入历史。新建、切会话、切项目保护未发草稿。生成中切项目会说明请求保留在原项目，异步结果只更新原会话。失权画面不显示聊天或成果正文。

## 演示入口与素材边界

URL参数用于评审取样，不作为产品功能按钮：

| 参数 | 画面 |
|---|---|
| `?scene=new` | 新会话 |
| `?scene=history` | 历史成果，右侧文档展开 |
| `?scene=failure` | 自动演示部分完成、视频失败 |
| `?scene=invalid` | 草稿依据失效，发送被阻止 |
| `?scene=preview-error` | 预览失败，可重试 |
| `?scene=denied` | 项目不可访问 |
| `?project=b` | 独立项目B会话上下文 |

安全帽图片为本地SVG示意素材，文档为页面设计中的固定演示内容；视频复用PG07短演示片段，播放时长按实际文件显示，不把界面需求中的90秒写成该素材的实际时长。文档/图片/视频不构成审核后的培训内容，也不验证真实模型效果。

资源、技能选择器为当前项目的独立演示数据，并未与PG07/PG13内存数据实时联动。PG07和PG13已增加进入本页的导航；项目A可返回这两个模块。项目B在本页演示会话与选择器隔离，因其他模块尚无项目B原型，其跨模块入口暂禁用；PG02尚未制作，切换项目使用本页选择弹窗承接。不是完整系统的项目路由验收。

刷新可恢复本地会话；刷新打断的模拟请求显示重试提示，不宣称服务端后台续跑。删除浏览器站点数据会清除会话。共享权限、服务端持久化及调用生效继续见Q04/Q16/Q17。
