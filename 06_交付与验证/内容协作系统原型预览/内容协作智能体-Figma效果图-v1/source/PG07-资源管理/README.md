## 样式与有意差异

复用资源后台A布局、当前实页#1890FF主色、#FF4D4F危险色、266px侧栏、60px顶栏、32px控件、4px圆角、14px正文、细线表格、白面板及浅蓝选中态。保留分类树和固定右操作列。

页面主本曾用240px侧栏作原型建议；本次用户明确要求系统规范，故采用实测266px。分类栏采用页面主本220px（而非旧截图约340px），适应四页签和当前字段布局；上传采用主本640px，扩展多文件队列。当前不是旧截图逐像素复刻。四类页签、合并资源入口来自当前业务设计；不沿用旧参考系统的课程/公告等菜单。原图人员水印不复制。

## 覆盖及边界

| 设计点 | 原型覆盖 |
|---|---|
| PG07.01 | 四类页签及类型独有列，切换清查询/分类/多选 |
| PG07.02 | 一级分类筛选、新增、重命名、重名校验、非空分类禁止删除 |
| PG07.03 | 名称/格式联合查询、回车查询、重置、无匹配 |
| PG07.04 | 本地选文件、拖入、格式检查、内存上传队列、成功/部分失败/重试/关闭保护 |
| PG07.05 | 四类演示列表、勾选、分页、横滚及固定操作 |
| PG07.06 | 图片缩放、文档样稿、音频播放、视频播放、不支持预览 |
| PG07.07 | 名称/分类/说明编辑，必填和长度限制，取消保护 |
| PG07.08 | 删除确认、已引用资源阻止、未引用演示资源可删除 |
| PG07.09 | 所选资源写入本地会话交接记录并展示；尚未跳到未制作的PG11完整页 |

所有业务数据为演示内存数据，刷新重置；上传不发送至服务器。音频是3秒测试音、视频是约1.5秒本地绘制动画，列表时长是排版示例，不能据此验证业务文件真实元数据。PDF/文本展示是原型文档样稿，不证明真实格式转换；不使用上传文件推定线上预览能力。上传的非图片文档仍需正式预览服务，本原型不作内容真实性核验。

外侧其他页面仅给范围提示，项目切换不模拟真实跨项目权限；项目隔离、接口、格式上限、删除依赖、真实生成与归档待后续研发。只读态通过地址参数role=readonly演示，type=image/doc/audio/video切换初始页签；scene=empty/error/loading展示特殊列表状态。控制参数不显示在产品画布。

[核验结果](核验结果.json)记录浏览器检查：17张截图；1440和1920画布；266/60/32尺寸、主色和圆角取值正确；1440无整页横溢；查询、切类型清查询、编辑校验/保存、未保存关闭保护、引用阻止删除、视频播放通过。浏览器脚本无异常。已目视检查1920主图、1440主图和上传失败图。

新增参数和操作仍为原型建议，不表示业务评审通过；Q04/Q15/Q16/Q17及真实能力核验继续保留。
