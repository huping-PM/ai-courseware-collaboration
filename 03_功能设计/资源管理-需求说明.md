## 1. 目标与范围

让项目成员集中维护和复用培训内容生产所需的图片、文档、音频、视频。各项目功能一致，资源数据按项目隔离；资源管理只能查询、预览、维护和引用当前有权访问项目的数据。

本条需求覆盖资源分类、查询、上传、列表、预览、编辑、删除，以及承接智能体手动保存的成果。智能体生成、技能/提示词管理、跨项目共享、自动归档不在本条实现范围。

项目隔离、四类资源、已完成成果可手动保存至资源库为用户已明确能力。以下单页四页签、格式和长度、引用保护等为现有原型设计方案，需评审后作为研发基线；提交禅道不等于已评审、已排期或已实现。

## 2. 页面与功能

入口为当前项目左侧“资源管理”。沿用系统设计规范：266px导航、60px顶栏、32px控件、4px圆角、主色#1890FF；页面内左侧220px分类栏，右侧查询、操作栏和资源表格。默认图片页签、全部资源，列表按更新时间倒序。

| 编号 | 功能 | 需求说明 |
|---|---|---|
| PG07.01 | 类型切换 | 图片、文档、音频、视频四页签；切换后清空查询、多选，分类回全部资源、页码回第一页，各类型分类独立。 |
| PG07.02 | 分类管理 | 最多5级树形分类，顶级为第1级；固定全部资源/未分类不计层级且不可维护。支持新增顶级、第1—4级新增子分类、重命名及删除。名称必填1—10字，同类型不重名；有资源或子分类时禁止删除；第5级不提供新增子分类且提交阻止超过5级；新增后展开路径并选中，删除后回全部资源。 |
| PG07.03 | 查询 | 名称包含匹配，与格式联合筛选，支持回车查询。重置清空名称和格式、保留分类，回第一页；分类切换清多选并回第一页。 |
| PG07.04 | 上传 | 按当前类型上传文件到当前项目与分类；支持多文件与拖拽、合法性检查、队列状态、部分失败及重试；成功项入表，失败项保留。 |
| PG07.05 | 列表 | 展示多选、名称、分类、格式、大小、更新人、更新时间、操作及类型特征。默认10条，可选10/20/50；长名称悬浮全文，未知元数据显示“—”，操作列固定。 |
| PG07.06 | 预览 | 图片可缩放/适应窗口；文档显示支持的只读正文或页码翻页；音视频支持播放、进度和音量，视频支持全屏。关闭停止播放，保留列表筛选和分页。 |
| PG07.07 | 编辑信息 | 修改名称、分类、说明，文件主体不替换。名称必填1—100字（不含只读扩展名），说明可选最多200字；校验或保存失败保留输入，取消未保存修改需确认放弃。 |
| PG07.08 | 删除 | 二次确认明确文件名；无引用资源可删，已引用或无法确认引用状态则阻止并说明原因；失败保留原列表数据。引用判定对象和服务端规则待Q15。 |
| PG07.09 | 已取消 | 按D031取消资源管理页用于对话，编号保留；在智能体输入区选择资源。 |

### 类型差异

| 类型 | 特征字段 | 当前原型上传格式 | 预览边界 |
|---|---|---|---|
| 图片 | 缩略图、尺寸 | JPG/PNG/WEBP | 大图、缩放、适应窗口 |
| 文档 | 文件图标 | PDF/DOCX/PPTX/TXT/MD | PDF翻页、TXT/MD正文；DOCX/PPTX提示暂不支持在线预览 |
| 音频 | 时长 | MP3/WAV | 播放暂停、进度、时长、音量 |
| 视频 | 封面、时长、分辨率 | MP4 | 播放器、进度、音量、全屏 |

格式列表仅为原型建议。单文件大小、批量数量、存储容量、编码和预览转换服务未确认，不据演示数值承诺正式上限。PG11原型保存视频为WEBM，与当前上传MP4白名单不同；正式支持矩阵须在Q15/Q17确认，不能按扩展名假装可播放。

## 3. 核心流程及异常

**上传：** 打开弹窗→显示所属项目只读、分类（默认当前分类，全部资源时默认未分类）→选择/拖入文件→逐项校验→提交合法待传文件→待上传/上传中/成功或失败→完成。非法格式不提交，其他合法项可继续；上传中防重复提交和直接关闭，未传/失败项关闭需放弃确认；成功项不重复上传，失败项可重试/移除。无真实进度时不显示虚假百分比，项目切换不得沿用旧队列。

**使用：** 切类型/分类或查询→预览确认→按需编辑。预览不支持时显示文件基本信息与原因，不伪造转换正文，不增未确认下载能力。加载失败可重试，空列表与查询无结果分别提示，删除或失去访问权限后清空旧预览。

**成果入库承接：** 用户在PG11对已完成的文档/图片/视频手动保存成功后，应可在同项目对应资源类型检索和预览实际保存文件；生成中/失败成果不入库，取消保存不入库，不自动归档。保存弹窗及防重复交互由PG11.13负责，本条负责资源列表承接与预览；持久化、重名处理、权限以及资源删除后会话保存标记联动待Q17。浏览器演示保存不是后端实现证据。

**权限：** 无项目访问权不得读取该项目资源；只读身份隐藏上传、分类维护、编辑和删除入口。提交时再次校验权限，失败保留可恢复输入并提示，不把隐藏按钮当服务端鉴权。角色矩阵、生成权限和跨项目访问规则按Q04确认。

## 4. 验收标准

以下为评审用验收候选，参数以评审后的版本为准。

1. 同一用户切换项目A/B，查询、分类、列表、预览、维护均不串项目；无权资源不能通过直接请求访问。
2. 四类资源展示各自特征列；切类型后旧条件/多选不残留，名称与格式联合查询、重置和分页结果正确。
3. 分类空名、超长、重名及超过5级均被阻止且输入保留；固定入口不可改，有资源或子分类时不可删；上传、编辑及成果入库通过树形分类选择器选择并显示完整路径。
4. 混合合法/非法文件时只提交合法项；部分成功后成功项可检索，失败项可重试且不会重复提交成功项；切项目不复用队列。
5. 图片能放大查看，文档按支持范围展示；音视频正常播放且关闭停止。不支持格式、编码错误和加载失败有明确反馈，无假内容/假播放成功。
6. 编辑名称、分类、说明后列表和预览信息一致，扩展名与文件主体不被改写；校验/保存失败保留输入，取消不改数据。
7. 删除先确认，无引用时成功删除；引用中或引用状态未知时阻止，失败不能从列表伪删除。
8. 行菜单及多选工具栏不提供用于对话；不影响PG11输入区选择资源。
9. PG11手动保存成功的文档/图片/视频可在同项目资源库找到并预览；其他项目不可见，取消/失败不产生资源记录。
10. 加载、无数据、查询无结果、加载失败、预览失败、无权限状态分别可辨识；只读无维护入口且接口拒绝越权操作。
