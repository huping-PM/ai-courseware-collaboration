版本：v2.0｜日期：2026-10-09｜状态：交互原型规范，待产品与设计评审。依据：Beautiful UI 官方组件及用户 D062—D064、D070、D072、D074 的交互与页面框架要求；D072 管理页采用 shadcn 风格。

[交互 Demo](../06_交付与验证/AI协作工作台UI风格方案/交互Demo.html) · [现行 UI 方案](AI协作独立工作台-UI重构方案.md) · [组件源码与许可](../04_原型与说明/AI协作工作台-风格探索/README.md)

## 1. 规范来源与应用边界

[Beautiful UI 官网](https://www.beautifului.dev/)提供 AI 原生界面的可复制组件。[官方源码](https://github.com/slev12397/beautiful-ui/tree/44a274e598395ab61e7c96c26fda2758780253b7)固定到提交 `44a274e598395ab61e7c96c26fda2758780253b7`，采用 [MIT 许可](https://www.beautifului.dev/license)。本项目保留了实际参照文件和[完整许可](../04_原型与说明/AI协作工作台-风格探索/THIRD_PARTY_LICENSES.md)。

Beautiful UI 是课件协作工作台及统一顶部框架的视觉与交互规范；本地 Demo 将相关 React/Tailwind 示例适配为可离线预览的原生页面。D072 起三个一级入口为课件协作、资源管理和智能体配置。后两页继续嵌入 PG07／PG13 主内容，管理组件改按用户指定的 [shadcn Blocks](https://ui.shadcn.com/blocks) 风格适配，业务交互保持原有规则。该适配使用原生 HTML/CSS，不表示已安装 shadcn React 组件。组件示例中的 CRM、工作流、屏幕操作等业务不会成为本平台需求。

规范优先关系：已确认业务规则与 D056 工作台布局 → 本文组件用法 → 官方基础样式与动效。后续新增组件先使用同一套表面、字段、按钮、状态与焦点规则，再处理业务差异。

## 2. 视觉基础

| 设计项 | 统一规则 |
|---|---|
| 表面层级 | 页面为浅灰，工作区与弹窗为白色，嵌入输入区和悬停态为低对比灰；用细边框区分层级 |
| 文字 | 主要内容用深墨色，说明用次级灰色，元信息用浅灰；中文内容优先保证可读性 |
| 圆角 | 标签 6px、表单控件 8px、卡片 10px、窗口 14px；主操作可使用胶囊形 |
| 阴影 | 基础按钮用极轻描边和阴影，卡片用浅阴影，弹窗使用更清晰的悬浮阴影 |
| 强调色 | 用于键盘焦点、链接和必要的交互反馈；进行中、完成状态同时配图标和名称，不只靠颜色 |
| 动效 | 悬停和切换使用短时过渡；系统要求减少动态效果时停止非必要动画 |
| 图标 | 使用一致的 SVG 线性图标，不以单字、问号或文字代替图标 |

令牌在[实际组件样式](../04_原型与说明/AI协作工作台-风格探索/beautiful-ui.css)中集中维护，不在各页面重新定义另一套颜色和圆角。

## 3. 组件与页面对应

| 官网组件来源 | 平台组件 | 关键状态与交互 |
|---|---|---|
| `SidebarNav`、`GlideMenu` | 左侧会话记录 | 220px 侧栏；40px 单行；选中、悬停、键盘焦点；名称右侧同行显示进行中/已完成图标；加号新建 |
| `SearchList` | 会话搜索、资源与技能选择 | 资源以四类型页签切换，多级分类树与名称搜索；具体文件和分类均可多选并混合引用，跨页签保留；分类浏览与引用勾选分开，解析时对重叠文件去重；技能按名称或说明搜索 |
| `Button` | 一级导航、画布、弹窗操作 | 主按钮、次按钮、透明工具按钮、图标按钮共用尺寸、禁用和焦点样式 |
| `ChatComposer` | 对话消息与输入 | 用户消息、智能体回复、成果入口分层；输入固定底部；Enter 发送、Shift+Enter 换行，输入法组合期间不发送 |
| `ThinkingState` | 处理过程 | 默认收起；可展开查看资料、技能、讲稿步骤；只展示可审阅的执行摘要 |
| `ToolChips` | 资源、技能、本地文件与已选引用 | 输入区左侧依次为 SVG 加号、资源、技能；已选标签可移除，随会话隔离 |
| `ContextCards` | 消息中的引用资料卡 | 展示资料类型、摘要和来源入口；打开资料前沿用项目权限规则 |
| `ApprovalCard` | AI 总结的项目技能草稿 | 显示名称、Markdown 正文、保存位置和可见范围；用户显式确认后保存 |
| `LoadingState` | 对话处理中的等待态 | 与执行完成态分开；产品界面使用“正在处理／处理完成”，接入能力在交付文档中说明 |
| 官方基础令牌的项目组合 | 画布、成果条、图片选区、上传确认表格、模型菜单、空态、提示 | 保持同一表面、按钮、字段和反馈体系；这些是本项目组合组件 |

`PromptBar`、`TaskRows`、`SelectionActions` 等组件已研究，当前 Demo 没有直接适配它们的源码。后续若使用，须另行记录实际映射。

## 4. 固定的工作台结构

单层顶部栏含课件协作、资源管理、智能体配置三个一级入口；右上角显示“返回数据资产管理系统”。原型返回本地宿主示意页，正式系统跳转地址仍需接入时配置。课件协作页左侧为会话记录，中央为文稿、图片、音频或视频画布及底部紧凑成果条，右侧为约 400px 对话区。顶部不添加第二层面包屑。成果条左侧的文稿、图片、音频、视频筛选竖排，单选，再次点击当前类型恢复全部；筛选不改变当前画布。文稿卡使用图标和文件名，图片只显示缩略图，音频使用波形缩略图，名称通过提示和可访问名称提供，视频显示首帧缩略图和播放标识。

右上角不再显示“新员工课程共创”。对话输入区左侧为本地文件加号、资源、技能，右下角为模型名称下拉。资源弹窗顶部是文档、图片、音频、视频四页签；每个页签左侧为独立多级分类树，右侧为当前类型资源列表与名称搜索。D074 起文件与分类均可多选、混合引用；点击分类名称浏览文件，勾选分类复选框加入分类引用，右侧文件可独立勾选。跨页签、搜索及浏览保留已选对象；父分类包含下级文件，实际读取清单对重叠文件去重。确认更新当前草稿，输入区分别呈现可逐项移除的文件／分类标签；取消不改变会话。无任何选择时不能确认。技能弹窗支持按名称和说明搜索，搜索隐藏不匹配项但保留其勾选状态。加号打开电脑文件选择器，可一次选择多个；选择后弹出逐文件确认表，默认仅用于当前会话，勾选“保存至资源库”才启用该文件的分类选择。取消不改变已有输入；确认后文件标签进入当前会话草稿，不自动发送。原型仅保留文件元信息与入库记录，未上传实际内容。

模型菜单向上展开，可用键盘选择，外部点击或 Escape 关闭。模型按会话保留，处理演示反馈期间禁止切换；当前展示的四个名称沿用既有原型示例，正式型号、权限与默认值以 Q10 核验为准。

画布工具条不设“成果”切换按钮，统一通过底部成果卡切换。Markdown 文档默认展示内容，点击“编辑”进入 Markdown 内容编辑态，同一按钮变为“保存”；保存成功后返回阅读态，不单列“预览”或“保存版本”。切换未保存内容时提供保存、放弃、继续编辑。画布右上角集中放置“引用到会话”和“保存到资源库”，不保留底部保存栏。图片、音频和视频不显示编辑按钮；图片提供“框选区域”，用户可在同一图片多次框选，分别选择提问或备注、填写内容并引用到右侧会话。每个选区以图片标识、版本及 0—1 归一化坐标记录，列表与编号标记可回看和再次引用；过小选区需重选。视频保持预览态。会话执行状态与业务任务审核状态分别表达，不共用图标文案。

## 5. Demo 可操作流程

进入[交互 Demo](../06_交付与验证/AI协作工作台UI风格方案/交互Demo.html)后直接显示全屏工作台。顶部可进入三个一级模块；左侧加号新建会话；中央工具栏编辑并保存 Markdown、引用成果或保存到资源库；底部成果清单切换文稿、图片、音频和视频；图片可多次框选提问或备注；右侧可筛选资源、选择技能、加入本地文件、切换模型、确认技能草稿并展开执行步骤。演示入口不叠加场景导航或验收说明，保留画布与对话空间。

原型界面按真实产品使用场景撰写文案，不在界面中出现“演示”“示意”“模拟”等评审提示。当前仍以本地预置内容展示状态及反馈，不连接真实 AI、媒体模型、权限或跨设备会话服务；此能力边界保留在交付文档。需要评审真实生成能力时，仍以[迭代功能设计](AI课件协作平台-迭代功能设计.md)中的 I03— I05 与后续接入验证为准。

## 6. 评审检查点

1. 全部可见组件遵循同一表面、按钮、输入和状态规则；弹窗与主页面无明显风格断裂。
2. 会话、新建、搜索、切换、草稿保护和内容隔离可操作。
3. 四类成果可预览、筛选和再次取消；媒体不出现 Markdown 编辑动作；图片支持两次以上独立框选并引用会话。
4. 资源按类型与分类筛选、本地多文件逐项入库选择、技能、模型切换、执行记录和人工确认能从对话区操作。
5. 键盘焦点可见，图标按钮有可访问名称；1440×900 无页面横向溢出。

本规范和 Demo 处于待评审状态，不能作为真实服务、权限或业务验收通过的证据。

## 7. D063 统一框架中的原页面

- 课件协作会话栏底部取消用户头像与姓名，其余工作台组件保持现有规范。
- 资源管理使用PG07原页面主内容，技能管理使用PG13原页面主内容；统一顶部导航归工作台框架。嵌入态隐藏PG07/PG13原侧栏、顶栏与重复页签，不改变列表、分类树、查询、分页、弹窗及业务逻辑。
- PG13原侧栏中的“技能管理／提示词管理”由统一框架内的二级切换承接。PG07/PG13独立入口不带嵌入参数时仍按原布局展示。
- D063 当时仅替换外框；D072 已授权两页管理组件采用 shadcn 风格，当前规范见下文。两轮均不证明原业务功能已接入服务。

## 8. D064 选择资源弹窗（历史，分类多选由D073替代）

类型切换使用四个互斥页签，不再使用资源类型和文档类型下拉框。每个页签单独保存关键词、分类勾选和树节点展开状态；分类父节点勾选包含所有下级资源，多分类勾选取并集，清除筛选恢复该类型全部资源。资源行复选框跨页签暂存，页签切换不清空已选；底部显示总选择数，取消丢弃本轮改动，确认后写入当前会话草稿。样例分类路径只用于验证树状交互，正式数据来源仍是项目资源分类。

## 9. D072 管理组件风格（2026-10-09）

用户指定 [shadcn Blocks](https://ui.shadcn.com/blocks) 为后台页面组件参考。参考 dashboard-01 的数据表与 sidebar-07 的分区表达，复用现有顶部三模块框架，不新增仪表盘统计卡或侧导航。顶部“技能管理”改为“智能体配置”，内部仍为技能管理／提示词管理；路由标识保留以兼容已有入口。

| 组件 | 管理页规范 |
| --- | --- |
| 按钮与字段 | 深色主操作、白底描边次操作、灰色占位；统一控件高度、圆角和焦点轮廓 |
| 页签 | 浅灰底分段页签，选中项白底、清楚显示选中状态 |
| 分类树 | 保留分类层级、数量与操作；浅灰选中和悬停背景 |
| 列表 | 圆角外框、横向分隔、清晰表头与行悬停；避免密集纵线和无数据大空白 |
| 状态与开关 | 标签、开关采用同一中性令牌，保留启停文案、权限和确认逻辑 |
| 弹窗与反馈 | 表单、详情、上传与确认使用同一边框、圆角、按钮和反馈体系 |

查询区域在列表操作区域之前；查询／重置与上传／新增保持各自区域。范围覆盖两管理页及其可操作浮层。工作台会话、四类成果、真实权限、模型调用和入库能力保持原有边界。当前为本地原型待评审；具体核验见交付记录。

## 10. D073 选择资源按单一分类引用（历史误解，已由D074纠正）

选择资源弹窗左树改为分类单选，右侧清单只预览，移除文件复选框。选择父分类包含下级全部文件；搜索只改变清单显示，不缩小引用集合。四类型页签保留，切换类型清空本轮分类选择。“全部分类”是未选择浏览态，未选或分类无可访问文件时禁止确认。

确认以一个分类下全部可访问文件替换当前草稿资源引用；取消不修改原引用。输入区以“分类路径＋文件数”整体标签呈现并整体删除，发送仍携带实际文件集合；会话隔离沿用现有规则。原D064跨分类／跨类型多选不再作为当前验收条件。详情、边界与验收见[UI方案第18节](AI协作独立工作台-UI重构方案.md)。

## 11. D074 文件与分类混合多选（2026-10-09）

文件和分类均使用复选框，可跨类型多选并同时引用；分类名称用于浏览，复选框用于引用，两者独立。分类包含下级文件，搜索与浏览不清空选择，分类引用不自动勾选其文件。文件／分类标签分别展示、分别移除。底部显示文件数＋分类数＋去重读取文件数；重叠内容按文件ID去重。

确认更新草稿，取消不改；重开恢复，多会话隔离，发送后清空草稿。消息保留两类引用对象及分类文件清单，结构化数据用于后续真实模型读取接入。现有本地原型仍是模拟响应，不声称模型已读取文件。D073单选限制属于已纠正的AI理解；当前规则见[UI方案第19节](AI协作独立工作台-UI重构方案.md)。
