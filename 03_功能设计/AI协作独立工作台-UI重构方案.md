## 1. 当前范围

本方案沿用 B 灵感工作室的工作区布局，课件协作工作台按 D057 采用 Beautiful UI 组件体系。D072 将一级导航展示名称调整为**课件协作、资源管理、智能体配置**；智能体配置内部保留技能管理与提示词管理。资源管理与智能体配置的管理组件按用户指定的 shadcn Blocks 风格调整，保留 PG07／PG13 既有业务内容与交互。业务范围与实际权限仍以已确认需求为准；本次 UI 调整不新增智能体编排或模型配置业务。

依据：用户四项布局修正记录D056；随后明确指定Beautiful UI组件工具重设计，记录D057；现有Markdown编辑、成果保存、资源/技能引用与项目权限仍按迭代需求继承。D054中把左侧视为业务任务列表的解释由本轮会话记录要求替代。

## 2. 页面布局

- 单层顶部栏：品牌、三个一级模块入口、项目上下文、右上角“返回数据资产管理系统”与用户入口。删除原第二层面包屑栏，不留空白占位。演示中的返回链接指向本地宿主示意页，正式地址待集成配置。
- 左侧会话记录：约220px宽，紧凑单行条目，标题旁提供独立SVG加号按钮新增会话。
- 中央画布：文稿、图片、音频、视频通过底部成果条切换；工具条显示成果名称、引用到会话、保存到资源库及当前成果可用操作，不再放独立“成果”切换按钮。
- 底部成果条：四类筛选竖排，文稿/图片/音频/视频横向展示；保持紧凑布局并为四类按钮保留完整点击区域。
- 右侧智能体对话：1440px桌面下约400px宽，比上一稿约330px加宽；消息区独立滚动、输入固定在底部。

尺寸为本轮原型布局规格，随容器适配；不把1440px视为真实系统唯一窗口尺寸。

## 3. 会话记录与新增

| 元素/操作 | 规则 |
|---|---|
| 条目 | 单行显示会话名称，过长截断并可查看完整名称；状态图标紧贴名称所在行右侧 |
| 进行中 | 使用环形/时钟SVG；悬停和可访问名称为“进行中” |
| 已完成 | 使用勾选SVG；悬停和可访问名称为“已完成” |
| 状态含义 | 指会话中的AI执行状态，不等同业务任务的待审核/审核通过；未发起执行的空会话可不显示状态图标，不新增第三状态文案 |
| 新增会话 | 点击标题旁加号，输入名称或使用默认名称，创建独立空会话并选中；原会话保留 |
| 切换 | 同步会话消息、输入草稿、引用与成果，避免沿用上一会话成果；筛选条件与选中成果随会话保留 |
| 未保存内容 | 新建、切换或离开时提供保存后继续、放弃改动、继续编辑；取消不丢失输入 |
| 权限 | 历史记录可见范围沿项目及会话权限，不新增“我的业务任务”授权语义；本地演示不证明服务端隔离 |

会话记录不提供管理员的业务任务分配、审核或业务完成动作。真实执行的终态、失败恢复与后台通知仍需结合既有处理记录需求深化，本轮不通过新增会话伪造业务完成。

## 4. 紧凑成果条

| 类型 | 呈现 |
|---|---|
| 文稿 | 文档SVG图标＋文件名称；名称截断时可查看完整名称 |
| 图片 | 仅缩略图，文件名通过提示和可访问名称提供 |
| 音频 | 波形缩略图，名称通过提示和可访问名称提供；点击切换音频预览 |
| 视频 | 首帧缩略图，可叠加小播放标识；原型采用首帧示意 |

左侧保留文稿、图片、音频、视频四个竖排筛选按钮，每类独立SVG图标；默认全部。点击一类仅显示该类，点击另一类切换筛选，再点当前类型恢复全部。筛选只影响清单，不自动切换画布。具体成果点击后才切换预览；未保存文稿先处理草稿。无成果或筛选无结果显示清楚空态。四类及命名依据用户2026-10-08明确要求（D070）。

压缩容器留白和卡片高度，保留可点击面积、选中边框及横向滚动。图片、音频、视频不能启用 Markdown 编辑；返回文稿后恢复“编辑”。文稿在“编辑→保存”同一按钮内完成本地版本保存；“保存到资源库”仍是独立动作，与业务审核区分。

## 5. 对话与内容操作

加宽后保持对话信息层级及输入习惯：Enter发送、Shift+Enter换行，中文输入法组合期间不发送。画布的“引用到会话”先将当前成果放入输入区，随下一条消息发送；图片可框选局部区域、选择“提问/备注”、填写内容后引用到右侧会话，同一图片可连续生成多个编号选区。参考资料和技能在输入区选择；对话经验先形成可读草稿，经人工确认保存项目技能。AI识别媒体意图的真实服务由既有需求约束，本原型只演示反馈。

## 6. 验收与边界

1. 顶部一级导航准确显示课件协作、资源管理、智能体配置，分别进入对应原型页；智能体配置内保留技能管理／提示词管理；右上角显示“返回数据资产管理系统”。
2. 第二层面包屑不存在，主工作区直接位于单层顶栏下。
3. 会话名称和两类状态图标在同一行；新增按钮可创建并选中独立空会话。
4. 成果条完整展示文稿、图片、音频、视频四类，筛选竖排可取消；对话约400px；1440×900无页面横向溢出。
5. 切换、新增保持草稿保护、会话内容隔离与原成果筛选行为；画布无额外成果按钮和底部保存栏，文档按钮为“编辑→保存”，图片两处以上选区分别可引用到会话。

当前状态：可审核本地原型；真实AI调用、跨设备存储、权限后端、视频首帧抽取和全量异常状态不由本次UI演示证明。原有Figma和正式业务入口未发布替换。

## 8. Beautiful UI组件重设计（D057）

### 8.1 来源与使用方式

用户指定[Beautiful UI](https://www.beautifului.dev/)，2026-09-28核验官网组件目录、Copy code / View code入口与[MIT许可](https://www.beautifului.dev/license)。官方源码见[beautiful-ui仓库](https://github.com/slev12397/beautiful-ui)；组件是可复制的React示例，本原型使用HTML/CSS/JavaScript，采用源码适配方式，并非安装一个同名运行服务。具体使用文件和保留许可随原型归档，见[组件映射与来源](../04_原型与说明/AI协作工作台-风格探索/README.md)。PromptBar、TaskRows、SelectionActions仅做考察，未作为本轮已使用源码组件。

### 8.2 全组件覆盖清单

| 工作台组件 | 对应来源与适配原则 |
|---|---|
| 顶栏、面板、分隔线 | globals.css中性色、层次、圆角与阴影体系；保留单层顶栏 |
| 会话列表、选中/悬停态 | SidebarNav；保持220px侧栏及40px单行会话 |
| 会话搜索、无结果 | SearchList；紧凑输入、即时过滤、清楚空态 |
| 新增、编辑、保存、关闭等按钮 | Button；统一主次层级、图标尺寸、禁用与键盘焦点 |
| 状态图标 | 基础图标与状态令牌适配；进行中与完成的同行状态，不引入业务审核状态 |
| 聊天容器、消息与结果卡 | ChatComposer；分清用户输入、智能体回复与成果入口 |
| 消息输入、引用与技能触发 | ChatComposer / ToolChips；保留Enter发送/Shift+Enter换行，无发送按钮 |
| 执行过程、调用标记 | ThinkingState / ToolChips / LoadingState；显示可解释的步骤摘要，演示记录不表示真实调用 |
| 资料选择及引用 | ContextCards；清楚展示名称与类型，使用当前项目可访问资料 |
| 技能草稿、保存保护等确认 | ApprovalCard；内容与动作分区，人工确认后才保存 |
| 文档工具条、编辑区、预览 | 基础按钮、字段与面板体系适配；仍只编辑Markdown |
| 图片/视频画布、返回动作 | 统一预览容器与浮层按钮；媒体编辑保存禁用 |
| 四类成果卡、竖排筛选 | 同一基础体系定制；保留紧凑容器、60px卡片与二次点击取消 |
| 空会话、空成果、无筛选结果 | 同一文字、图标和容器体系；不给空会话附加旧成果 |
| 弹窗、复选框、提示反馈 | 同一字段、边框、阴影、焦点与反馈规范 |

这是组件适配清单，不表示把官网所有业务示例塞入本产品。官网中的CRM表格、工作流编辑器、屏幕操作等不在本轮业务范围。

### 8.3 设计与交互约束

采用灰白背景、深色文字和克制的状态色，减少大面积装饰。基础控件圆角约8px、卡片约10px、浮层约14px；使用轻边框和细阴影区分可交互区域。中文排版保持可读字号；悬停、选中、禁用、键盘焦点不能互相混淆。动画尊重系统减少动态效果偏好。

本轮为完整组件视觉适配，不改变权限、业务范围、成果保存语义及会话状态含义。D056布局与交互验收继续有效；另核对新增会话、参考选择、技能选择、技能确认及未保存保护浮层的统一性。最终核验以[本轮交付记录](../06_交付与验证/AI协作工作台UI风格方案/交付与核验.md)为准。

## 9. D060 画布与图片局部提问补充

| 场景 | 入口与规则 | 验收观察 |
| --- | --- | --- |
| 文档编辑 | 仅 Markdown 内容；点击“编辑”进入源码输入，同一按钮变“保存”；保存成功回到阅读态并更新本地版本号；空文档阻止保存并保留编辑态 | 页面不再同时出现“预览”“保存版本”按钮 |
| 成果引用 | 文稿、图片、音频、视频均可点击画布右上角“引用到会话”；输入区显示待发送引用，发送后随消息展示；关闭引用不清空文字 | 当前成果名称及类型正确，切换会话不误带旧引用 |
| 保存到资源库 | 入口位于画布右上角；编辑未保存时先保存文档；演示反馈注明仅本地模拟，服务端入库需真实接入 | 不在画布底部占用独立栏位 |

| 局部引用数据 | 每条记录包含当前会话、图片 ID、图片版本、选区归一化 x/y/w/h、类型、文字与编号；同图可重复添加，编号可回看、再次引用 | 刷新后本地演示记录仍可恢复；正式存储与图片版本一致性按迭代功能设计接入 |

原型使用浏览器本地存储与预设 AI 反馈。图片当前是示意插画，正式图片像素坐标映射、AI 图像理解、真实入库、权限和服务端持久化仍需开发接入及联调验收。

## 10. D061 对话输入区与资源入口

1. 顶栏右侧仅显示返回数据资产管理系统和用户入口，移除项目名称“新员工课程共创”。上传确认弹窗仍显示所属项目，帮助用户判断入库范围。
2. 输入区左下从左到右为本地文件加号、资源、技能。资源弹窗按名称、资源类型和分类组合筛选；切换类型后分类选项跟随当前类型，结果列出类型与分类。原型分类为演示数据，正式分类复用 PG07 当前项目分类树。
3. 点击加号打开电脑文件选择器，支持多选。选择后弹窗逐行展示文件名、类型、大小、本地选择状态、是否保存至资源库、分类及移除操作。默认不入库；勾选某文件后仅启用该行分类。取消或移除不清空输入文字；确认后文件标签加入当前会话草稿，不触发发送。演示不上传原文件，只保留元信息，真实上传/失败重试与入库结果按既有需求接入。
4. 输入区右下为模型胶囊，下拉向上展开；当前选项可见，支持键盘与 Escape，选择随会话切换。演示处理中禁用切换。当前四个型号仅复用 PG11 原型示例，不视为正式服务清单，真实模型与权限仍见 Q10。
5. 验收重点：资源类型与分类筛选有效；两个文件可分别选择是否入库；取消、移除、确认、发送和会话切换不串数据；模型选择随会话恢复；1440×900 下无横向溢出。

## 11. D062 资源多选、技能搜索及产品文案（资源多选为历史）

1. 资源选择弹窗采用左右分栏：左侧按当前项目的资源分类树切换范围，右侧显示当前分类及其子分类资源。右侧提供资源名称关键词、资源类型和文档格式筛选；文档格式仅在资源类型为“文档”时启用。分类树数量包含子分类资源，不制造额外分类。当前样例分类为“培训素材”“未分类”，正式分类以项目资源数据为准。
2. 资源行使用复选框。跨分类、跨搜索条件切换时暂存勾选，底部持续显示已选数量；取消关闭弹窗且不改会话引用，确认后统一加入当前会话输入区。引用标签可逐项移除；发送后随该条消息展示并清空输入区，切换会话时保持隔离。
3. 技能选择弹窗增加关键词搜索，匹配名称、类型和说明；隐藏不匹配项时保留已勾选状态，提供结果数量和无结果提示。
4. 产品界面只呈现用户能理解的状态与动作，不显示“演示／示意／模拟／未连接服务”等评审文案。原型的本地数据与未接服务边界在交付说明中记录，不将界面文案作为真实服务实现证据。

## 12. D063 管理页面接入统一框架

1. 课件协作左侧会话栏底部不再显示用户头像与姓名；会话搜索、新建和列表位置不变。
2. 顶部“资源管理”加载[PG07资源管理原型](../04_原型与说明/PG07-资源管理/资源管理原型.html)的主内容。保留图片／文档／音频／视频页签、分类树、查询、资源表、分页及原有弹窗与状态；隐藏其原侧栏、顶栏及重复页签。
3. 顶部“技能管理”加载[PG13智能体配置原型](../04_原型与说明/PG13-智能体配置/智能体配置原型.html)的主内容，保留技能和提示词列表、筛选、操作、表单、确认及版本查看。新框架在内容上方提供“技能管理／提示词管理”切换，替代原侧栏子菜单；隐藏PG13原侧栏、顶栏及重复页签。

## 13. D064 选择资源弹窗的类型页签与分类树（历史，分类多选由D073替代）

1. 弹窗顶部以“文档、图片、音频、视频”四页签切换当前资源类型，移除原“资源类型”和“文档类型”下拉框。页签显示该类型资源数量；右侧仅列当前页签下的资源，保留名称关键词搜索和资源行复选框。
2. 每个资源类型拥有独立分类树与列表。分类按路径逐级展示；展开／收起箭头与分类复选框是分离操作，可同时展开多支、多级。分类勾选是筛选条件，父分类覆盖其下全部子分类；同一页签勾选多个分类时取并集。未勾选时显示该类型全部资源，“全部分类／清除筛选”清空该页签分类条件。
3. 页签切换时保留各页签的分类勾选、展开状态和关键词；已勾选的资源也跨页签保留。点击取消不写入会话，点击确认后将所有类型的已选资源统一加入当前会话待发送引用，延续D062的发送及会话隔离规则。
4. 当前样例资源只有少量文件，选择弹窗为现有文件提供多级样例分类路径，用于验证树状交互；资源管理PG07的业务内容与分类数据不因本弹窗调整。正式分类树应从当前项目资源分类数据读取，不能将样例路径视为业务定稿。

## 18. D073 单一分类整体引用（历史误解，已由D074纠正）

本节记录AI对用户上一轮表述的单选解释，用户随后明确要求文件与分类均可多选，故本节不再有效。此前选择资源弹窗由跨分类／跨类型文件多选改为分类单选，替代D062／D064相应选择规则；四类型页签、树层级、展开／收起与名称搜索保留。

1. 左侧单选一个分类，选另一个即替换；父分类沿用原规则，包含全部下级分类中的文件。右侧是文件预览清单，移除逐文件复选框。
2. “全部分类”只用于浏览；未选分类或所选分类没有可访问文件时，“确认引用”禁用。数量按当前项目可访问文件计算，不越过权限边界。
3. 名称搜索只筛选显示清单，不减少已选分类的全部引用文件；同时说明匹配数量与该分类文件总数，避免把零搜索结果误认为分类为空。
4. 切换资源类型清空本轮分类选择，防止跨类型或分类累计。取消关闭不改变当前会话已有引用；确认用当前分类完整文件集合替换当前资源引用，保留消息文字。
5. 输入区展示分类路径及文件总数，支持整体移除，不逐文件删减；重开弹窗恢复已确认分类。发送时携带该分类本次确认的实际文件集合，发送后清空草稿引用；草稿随会话隔离。已有逐文件历史引用不伪造分类归属，新的确认按本规则替换。

这是当前可审核原型交互规格。真实分类、权限、引用时文件版本与后端读取能力仍需开发联调；本次不建立“自动包含未来新增文件”的服务承诺。本地文件上传、资源管理页的分类维护与批量操作不受此调整影响。核验见[交付记录](../06_交付与验证/AI协作工作台UI风格方案/交付与核验.md)。

## 19. D074 文件与分类混合多选引用（2026-10-09）

用户澄清：“需要能够多选具体的资源文件，也要能够多选资源分类，然后引用到对话窗口，由大模型去读取我引用的资源文件或资源分类”。D073 的单选分类、移除文件选择限制源于AI误解，本节替代该限制。引用对象包括具体文件和资源分类，两者可以同时选择。

1. 左侧分类复选框用于引用分类，可多选；分类名称用于浏览该分类文件，箭头用于展开／收起。这三种操作独立，浏览不会自动勾选分类。右侧文件复选框用于多选具体文件。
2. 文件与分类选择跨类型页签、搜索和分类浏览保留。搜索只改变显示；分类引用始终包含该分类及下级的可访问文件。“全部分类”是浏览入口，不作为真实分类引用。
3. 分类勾选不自动把其文件转成逐文件勾选；输入区分别展示文件标签及“类型／完整路径／文件数”分类标签，各自可删除。移除分类保留独立选中的文件，移除文件也不缩小已引用分类范围。
4. 底部显示所选文件数、分类数及去重后的读取文件数。文件与分类重复、父子分类重叠时保留用户所选对象，但实际读取文件ID取并集，不重复读取。
5. 确认更新当前会话草稿引用对象，取消保留旧草稿；重开恢复已确认对象。无任何对象时禁用确认；空分类可表达为0文件引用，不伪造可读取内容。草稿引用随会话隔离，发送后清空当前草稿。
6. 消息保留具体文件和分类对象，分类可展开查看本次解析文件。后端接入时需接收文件ID及分类标识、类型、路径和当前项目／会话上下文；按权限解析分类资源、读取文件内容，再交给模型。原型保留结构化引用对象及去重文件快照，演示发送与历史回看，不代表已经调用真实模型。

本次明确了引用意图与前端交互。真实文件读取、分类稳定ID映射、权限复核、文件解析／版本、分类变更后的读取时点、上下文容量和失败处理依赖后端联调，不在静态原型中作已实现承诺。当前样例通过类型与完整路径标识分类，正式数据应使用服务端分类ID。旧单分类草稿及逐文件引用按原含义兼容，不改造成另一种引用对象。本地文件上传及资源管理操作沿用既有规则。核验见[交付记录](../06_交付与验证/AI协作工作台UI风格方案/交付与核验.md)。
